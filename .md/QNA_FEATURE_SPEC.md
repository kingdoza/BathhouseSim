# QNA — 급수·배수 시스템과 욕탕 물 기능 명세

각 질문의 `답변:` 뒤에 선택지를 하나 적어 주세요. 선택지와 다른 결과를 원하면 원하는 동작이나 수치를 직접 적어도 됩니다. 하나의 질문은 하나의 사용자 관찰 결과만 다룹니다.

## 확정 전제

- 각 욕탕에는 그 욕탕만 제어하는 급수밸브와 배수레버가 있습니다.
- 플레이어는 급수밸브 또는 배수레버를 바라보고 `E`를 눌러 각각 독립적으로 여닫습니다.
- 급수밸브를 열면 닫힌 지점에서 시계방향으로 돌아가고, 지정된 물줄기 Niagara System이 활성화되며 욕탕의 물이 증가합니다.
- 급수밸브를 닫으면 원래 닫힌 지점으로 반시계방향 회전하고, 물줄기 Niagara System이 비활성화됩니다. 배수 중이 아니라면 현재 물의 양은 유지됩니다.
- 배수레버를 열면 닫힌 지점에서 시계방향으로 지정 각도만큼 돌아가고 욕탕의 물이 감소합니다.
- 배수레버를 닫으면 원래 닫힌 지점으로 반시계방향 회전하고 배수가 멈춥니다.
- 급수와 배수가 동시에 열려 있으면 `급수량 - 배수량`의 순변화가 적용됩니다. 기본 배수량은 기본 급수량보다 큽니다.
- 물의 양은 `0~100%` 범위를 벗어나지 않습니다.
- 물이 100%에 도달하면 급수밸브는 자동으로 닫히고 물줄기도 비활성화됩니다. 배수레버 상태는 바뀌지 않습니다.
- 손님은 입욕 허용 수위 이상인 욕탕에만 들어갈 수 있습니다.
- 모든 욕탕은 Level 개별 override 없이 전역 공통 입욕 임계치 `80%`를 사용합니다.
- NPC가 욕탕을 탐색·선택·예약·입장할 때 임계치 미만인 욕탕은 설치되지 않은 욕탕과 동일하게 취급하며, 유효한 후보에 포함하지 않습니다.
- 예약 후 임계치 미만이 되면 해당 욕탕이 없어진 것처럼 예약과 이동을 중단하고 다른 유효한 욕탕을 탐색합니다.
- 기존 사전 샤워 완료부터 시작하는 60초 전체 입욕 단계 제한시간은 유지합니다.
- 별도로 저장하는 실제 욕탕 체류시간은 유효한 욕탕 안에서 실제 입욕한 시간만 누적하며, 탐색·이동·입퇴탕 전환과 knockdown 시간은 제외합니다.
- 욕탕 미사용이나 유효 욕탕 탐색 실패는 만족도를 변경하지 않습니다. 수건 부족처럼 다른 기능이 소유한 만족도 규칙은 유지합니다.
- 욕탕 회수에는 기존의 “모든 슬롯이 예약·사용되지 않음” 조건과 새 “물이 0%임” 조건을 모두 적용합니다.
- 회수된 욕탕의 물은 보존하지 않으며, 다시 설치하면 빈 상태입니다.

## Q1. `E`를 눌렀을 때 물의 증감과 제어부 회전은 언제 시작·정지할까요?

- A: 입력이 승인되는 즉시 논리 상태와 물 증감이 바뀌고, 밸브·레버는 설정된 시간 동안 목표 각도로 부드럽게 회전
- B: 밸브·레버가 목표 각도에 도달한 순간부터 논리 상태와 물 증감이 변경
- C: 논리 상태와 밸브·레버 각도를 모두 즉시 전환하며 중간 회전 표현은 없음
- 권장안: A — 조작 반응은 즉각적이면서 회전 동작도 눈으로 확인할 수 있습니다. 급수 닫기는 입력 즉시 물줄기를 끕니다.
- 답변: A

## Q2. 밸브·레버가 회전 중일 때 플레이어가 다시 `E`를 누르면 어떻게 할까요?

- A: 목표 각도에 도달할 때까지 추가 입력을 받지 않고 `작동 중`으로 표시
- B: 현재 각도에서 즉시 반대 방향으로 전환
- C: 마지막 입력 하나를 예약해 현재 회전이 끝난 직후 반대 동작 실행
- 권장안: A — 빠른 연타로 논리 상태와 보이는 각도가 어긋나는 일을 막고 결과를 쉽게 예측할 수 있습니다.
- 답변: A

## Q3. 탕 종류마다 밸브·레버의 회전축과 열린 각도를 어디까지 다르게 조정할까요?

- A: 닫힌 authored 자세를 원점으로 삼고 탕 종류별 local 회전축·열린 각도·회전 시간을 지정하며 Level 개별 욕탕 override도 허용
- B: 탕 종류별 값은 지정하지만 Level 개별 욕탕 override는 허용하지 않음
- C: 모든 탕이 같은 회전축·열린 각도·회전 시간을 사용
- 권장안: A — 탕 종류별 급수·배수 방식 확장과 서로 다른 메시 pivot을 수용할 수 있습니다.
- 답변: A

## Q4. 탕별 급수량과 배수량은 어떤 단위로 조정할까요?

- A: 초당 수위 퍼센트 포인트(`%/s`)로 지정하고 탕 종류별 기본값과 Level 개별 override를 허용
- B: 빈 탕을 가득 채우는 시간과 가득 찬 탕을 비우는 시간(`초`)으로 지정
- C: 욕탕 용량(`L`)과 급수·배수 유량(`L/s`)을 각각 지정
- 권장안: A — 두 장치를 동시에 열었을 때 순변화를 바로 계산할 수 있고, 화면의 0~100% 수위와도 직접 대응합니다.
- 답변: A

## Q5. 첫 욕탕 타입의 기본 급수·배수 속도는 어느 정도로 할까요?

- A: 빈 탕 급수 약 30초, 가득 찬 탕 배수 약 20초
- B: 빈 탕 급수 약 60초, 가득 찬 탕 배수 약 30초
- C: 다른 시간을 직접 지정
- 권장안: A — 수직 구현에서 상태 변화를 충분히 관찰하면서도 검증 대기 시간이 길지 않습니다.
- 답변: 빈 탕 급수 약 15초, 가득 찬 탕 배수 약 10초

## Q6. 게임 시작 시 선배치 욕탕의 물과 제어부 상태는 어떻게 할까요?

- A: 모든 욕탕이 0%, 급수밸브 닫힘, 배수레버 닫힘으로 시작
- B: 새로 설치한 욕탕만 빈 상태로 시작하고 선배치 욕탕은 Level별 초기 수위·제어 상태를 지정
- C: 모든 욕탕이 100%, 급수밸브 닫힘, 배수레버 닫힘으로 시작
- 권장안: A — 새로 설치한 욕탕과 선배치 욕탕의 시작 규칙이 같고 플레이어가 직접 준비 과정을 수행합니다.
- 답변: A

## Q7. 수위가 0%에 도달해도 배수레버가 열려 있으면 어떻게 할까요?

- A: 레버와 배수 상태는 열린 채 유지하고 수위만 0%에서 고정; 이후 급수를 열면 두 유량의 순변화를 계속 적용
- B: 0% 도달 시 배수레버도 자동으로 닫힌 지점으로 돌아감
- 권장안: A — 급수만 100%에서 자동 폐쇄된다는 규칙과 대칭을 임의로 추가하지 않고, 열린 장치 상태를 일관되게 유지합니다.
- 답변: A

## Q8. 손님의 입욕 허용 수위는 어떻게 조정할까요?

- A: 탕 종류별 기본값 `50%`, Level 개별 욕탕 override 허용
- B: 탕 종류별 기본값 `75%`, Level 개별 욕탕 override 허용
- C: 모든 탕에 전역 고정값 `50%` 적용
- 권장안: A — 반 이상 채운 탕부터 사용할 수 있고, 향후 탕 종류별 차이를 확장할 수 있습니다.
- 답변: 탕 공통 기본값 80%, 개별 욕탕 오버라이드 없이 모든 욕탕이 한 임계점을 공유함

## Q9. 손님이 욕탕을 고른 뒤 입장하기 전에 수위가 기준 미만으로 떨어지면 어떻게 할까요?

- A: 욕탕 선택·예약 시와 실제 입장 직전에 모두 재확인하고, 기준 미만이면 예약을 풀고 다른 욕탕을 찾거나 대기
- B: 예약할 때만 확인하며 이후 수위가 떨어져도 예약한 손님은 입장
- C: 실제 입장 직전에만 확인하며, 이동 중 기준 미만이면 도착한 뒤 예약을 풀고 다시 탐색
- 권장안: A — 이미 기준 미만인 탕으로 불필요하게 이동하거나 낮은 수위에 입장하는 일을 막습니다.
- 답변: A

## Q10. 손님이 이미 들어간 뒤 수위가 허용 기준 미만으로 떨어지면 어떻게 할까요?

- A: 현재 손님은 정상 체류를 계속하고 새로운 손님만 입장 불가
- B: 현재 체류 구간을 끝낸 뒤 욕탕에서 나와, 남은 입욕 시간이 있으면 다른 적격 욕탕을 탐색
- C: 즉시 욕탕에서 나와 남은 입욕 단계를 종료하고 다음 샤워 단계로 진행
- 권장안: A — `일정 퍼센트 이상일 때만 들어간다`는 입장 조건을 그대로 적용하고 진행 중 행동을 갑자기 중단하지 않습니다.
- 답변: 임계치 미만이 되는 즉시 현재 체류를 끝내고 욕탕에서 나옵니다. 남은 총 입욕 시간이 있으면 다른 유효한 욕탕을 탐색합니다.

## Q11. 입욕 가능한 수위의 빈 욕탕이 하나도 없을 때 기존 60초 총 입욕 시간은 어떻게 할까요?

- A: 기존처럼 계속 흐르며 손님은 적격 욕탕을 기다리고, 시간이 끝나면 입욕하지 못했더라도 다음 샤워 단계로 진행
- B: 적격 욕탕이 생길 때까지 총 입욕 시간을 일시 정지
- C: 별도 탐색 제한시간 동안만 기다리고, 만료되면 만족도 변경 없이 다음 샤워 단계로 진행
- 권장안: C — 전체 입욕 단계의 60초 제한을 유지하면서 유효한 욕탕을 무기한 기다리지 않습니다.
- 답변: C. 유효한 욕탕을 최대 10초 동안 탐색하고, 만료되면 만족도 변경 없이 다음 샤워 단계로 이동합니다. 그때까지 누적된 실제 욕탕 체류시간만 보존합니다.

## Q12. 욕탕이 손님에게 예약됐거나 사용 중일 때 플레이어가 급수·배수를 조작할 수 있을까요?

- A: 예약·사용 여부와 관계없이 두 장치를 모두 조작 가능
- B: 예약 중에는 가능하지만 손님이 들어간 동안에는 두 장치 모두 조작 불가
- C: 급수는 항상 가능하지만 손님이 들어간 동안 배수만 조작 불가
- 권장안: A — 플레이어의 수위 관리 자유도를 유지하며, 입욕 중 수위 저하는 Q10의 계약으로 처리합니다.
- 답변: A

## Q13. 욕탕의 현재 물 양은 월드에서 어떻게 보여줄까요?

- A: 물 표면이 0~100% 수위에 맞춰 연속으로 오르내리고 0%에서는 숨김; 별도 숫자 UI 없음
- B: 비어 있음·부분·가득 참의 몇 단계로만 물 외형을 전환
- C: 연속 물 표면과 함께 조준 prompt에 현재 퍼센트도 표시
- 권장안: A — 수위 증감을 직접 볼 수 있으면서 상호작용 UI를 복잡하게 만들지 않습니다.
- 답변: A

## Q14. 100% 도달로 급수밸브가 자동 폐쇄될 때 어떤 피드백을 줄까요?

- A: 수동 닫기와 같은 부드러운 반시계방향 회전과 물줄기 비활성화만 수행
- B: A와 함께 짧은 화면 알림을 표시
- C: 밸브를 닫힌 각도로 즉시 전환하고 물줄기를 비활성화
- 권장안: A — 보이는 장치 동작만으로 원인을 전달하고 자동 동작과 수동 동작의 외관을 통일합니다.
- 답변: A

## Q15. 수위가 0%지만 급수밸브나 배수레버가 열려 있을 때 욕탕 회수는 어떻게 할까요?

- A: 모든 슬롯이 비어 있고 수위가 0%면 회수를 허용하며, 회수 완료 시 열린 장치를 자동으로 닫고 재설치도 닫힌 상태로 시작
- B: 수위 0%, 모든 슬롯 비어 있음, 급수밸브·배수레버 모두 닫힘을 전부 만족해야 회수 허용
- C: 수위와 슬롯 조건만 확인하고 열린 장치 상태를 회수 아이템에 보존해 재설치 시 복원
- 권장안: A — 사용자가 요청한 빈 욕탕 회수 조건을 유지하면서 활성 Niagara나 열린 제어 상태가 제거 과정에 남지 않습니다.
- 답변: A

## Q16. 손님의 입욕 자체가 욕탕 물의 양을 바꿀까요?

- A: 바꾸지 않으며 물 양은 급수와 배수로만 변함
- B: 손님 한 명이 욕탕에서 나갈 때마다 고정 퍼센트 감소
- C: 손님이 들어가 있는 동안 별도 사용 유량으로 계속 감소
- 권장안: A — 이번 범위를 급수·배수 관리와 입장 수위 조건에 집중하고, 물 소비·오염은 이후 기능으로 분리할 수 있습니다.
- 답변: A

## Q17. 플레이어가 열쇠·장비·설비 아이템 등을 들고 있을 때도 밸브와 레버를 조작할 수 있을까요?

- A: 들고 있는 물건과 관계없이 조작 가능
- B: 완전히 빈손일 때만 조작 가능
- C: 열쇠·장비는 든 채 조작할 수 있지만 설비 아이템을 들고 배치 중일 때는 조작 불가
