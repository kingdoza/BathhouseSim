# 설계 입력 — 상점 확장과 개봉 물품 흩어짐

## 목적과 상태

상점 수직 구현(샤워기)에 이어 나머지 설비 6종을 판매하고, 배송 상자를 열 때 물품이 정면에 무작위로 촘촘히 모여 겹쳐 생긴 뒤 서로 밀어내며 튀도록 바꾼다.

- 2026-09-28 사용자가 상점 화면과 샤워기 수직 구현 완료를 알리고 커밋했다(`94f0f11 상점/배송 수직구현 완료`). 수직 단계의 기능 계약 원문은 그 커밋의 이 파일에 있고, 구현 정본은 [Architecture/ShopSystem.md](Architecture/ShopSystem.md)다.
- 사용자 요청에 따라 이 파일에서 수직 단계 내용을 제거하고 이번 확장 단계만 기록한다.
- 사용자 선택 정본: [QNA_FEATURE_SPEC.md](QNA_FEATURE_SPEC.md) Q1~Q30. 이번 단계 관련은 `확장 단계 — 개봉 물품 배치 변경` 절과 Q26~Q30이다. 전체 답변 완료, 미확정 사용자 선택 없음.
- 이 기능 계약은 사용자 승인 대기 상태다. 승인 전에는 아키텍처·구현 단계로 넘기지 않는다.

이 문서는 플레이어 입력, 월드 결과, 실패 경로, Editor 조정값과 수용 기준을 정한다. 클래스, 상태 소유자, 데이터 구조, 물품 생성 위치 계산·공간 탐색 방법과 파일 구성은 설계 단계가 결정한다. 단, 튐 연출의 방법(물품끼리 일부 겹친 생성과 엔진 충돌 해소)은 Q30 B에 따라 사용자가 지정했다.

## 판매 상품 확장

- 판매 상품을 욕탕·샤워기·세탁기·건조기·보일러·쿨러·순환기 7종으로 늘린다. 락커는 판매하지 않는다.
- 추가 6종은 샤워기와 같은 흐름을 따른다: 상점 카드 표시·담기, 주문·결제, 배송, 상자 내용 표시, 개봉, 배치, 쓰레기통 버리기.
- 여러 종류를 한 장바구니에 담아 한 번에 주문할 수 있고, 한 주문은 상자 하나로 온다. 상자 내용 요약에 모든 종류와 수량이 보인다.
- 구매한 설비는 새로 설치한 설비와 같은 상태로 동작한다. 보일러·쿨러·순환기는 가동수치 0으로 시작한다.
- 상품 카드가 영역을 넘으면 상품 목록만 세로로 스크롤되고 장바구니 패널은 항상 보인다.

## 개봉 물품이 나오는 위치

### 모이는 모양

- 물품은 플레이어 정면 기본 100cm 거리 지점을 중심으로 한 3차원 영역 안의 무작위 위치에 생긴다.
- 영역은 물품 수와 크기에 맞춰 필요한 만큼만 넓어진다. 한 개든 열 개든 넓게 흩어지지 않고 오밀조밀하게 모인다.
- 물품마다 생기는 높이가 제각각이라 떨어지는 순간이 조금씩 다르다. 가장 낮은 물품도 바닥보다 위에서 생긴다.
- 방향은 좌우 방향(수직축 회전)만 물품마다 무작위다. 모두 선 채로 생겨 떨어진다.
- 같은 내용의 상자라도 열 때마다 배치가 달라진다.

### 튀는 연출

- 같은 상자에서 나온 물품끼리는 일부 겹친 채 생긴다. 엔진이 겹침을 풀며 서로 밀어내 나타나는 순간 약간 튄다(Q30 B).
- 튀는 세기는 겹치는 정도로만 조정한다. 밀려나는 속도에 별도 상한은 두지 않으며, 가끔 멀리 날아가거나 설비 위처럼 손이 닿기 어려운 곳에 떨어지는 것도 연출로 허용한다(Q29 B).
- 겹침으로 생기는 튐 외에 추가 속도는 주지 않는다. 이후는 중력으로 떨어진다(Q28 A).
- 튀고 떨어지면서 물품끼리 부딪혀 쌓이거나 구르는 것은 물리에 맡기고 되돌리지 않는다.

### 막힘과 금지

- 물품은 벽·바닥·기존 물체·손님과 겹쳐 생기지 않는다. 겹침 허용은 같은 상자에서 나온 물품끼리만이다.
- 정면 영역이 벽·물건·손님으로 막히면 물품 무리 전체를 플레이어 쪽으로 당기며 빈 공간을 찾는다. 당긴 위치에서도 같은 무작위 모임과 튐을 쓴다.
- 플레이어 위치까지 당겨도 막히면 그 자리 위쪽으로 물품을 쌓아 생성해 떨어뜨린다. 이 최후 경로에서도 물품끼리 일부 겹침과 튐을 허용한다.
- 어느 경우에도 물품이 벽 너머, 천장 위, 맵 밖에 생기거나 튀어서 그곳으로 빠져나가지 않는다.
- 개봉은 항상 성공하며 상자가 남는 경우는 없다.
- 튀거나 떨어지는 물품은 플레이어를 밀지 않는다.
- 나온 물품은 일반 설비 아이템이다. E로 들고 G로 내려놓고, 들면 기존처럼 배치할 수 있다.

## 기존 기능 유지 범위

- 수직 단계에서 구현된 상점 기능 전체를 회귀 없이 유지한다: 탭, 상점 화면, 장바구니·수량 상한, 결제·잔액 부족, 잔액 HUD, 배송 목록·딜레이·대기, 배송 지점 쌓기, 도착 알림, 상자 휴대·내용 표시, LMB 즉시 개봉·컴퓨터/배치 모드 LMB 우선, 쓰레기통(7종·상자만, 락커·열쇠·레벨 도구 불가, 환불 없음). 회귀 기준은 커밋 `94f0f11` 계약의 `유지` 시나리오 SHOP-001~017, 021~031, 036, 037이다.
- 설비 배치·회수·용량·노동 가동 규칙
- 관련 없는 기존 결함을 포괄적으로 수정하는 작업으로 확대하지 않는다.

## Editor authoring 기대

- 추가 6종을 판매 상품으로 켜고 표시 이름·가격·아이콘을 정한다. 아이콘은 임시 이미지나 이름 표시로 대신할 수 있고, 가격은 확장 검증 중 조정한다.
- 개봉 물품의 촘촘함을 조정할 수 있어야 한다. 기본값은 PIE에서 "약간 튀는" 느낌을 보고 정하며, 큰 물품(욕탕)과 작은 물품(샤워기)이 섞인 상자로도 확인한다.

## 단계 판단

- 흐름은 수직 단계와 같고 새 입력·UI가 없으므로 추가 수직 구현 없이 한 단계에서 완성한다.
- 개봉 배치 변경은 샤워기를 포함한 7종 모두에 적용한다.
- 대표 시나리오: 보일러 1·샤워기 2·욕탕 1을 한 번에 주문해 도착한 상자를 열면, 정면에 네 물품이 제각각 방향과 높이로 촘촘히 겹쳐 생기며 서로 튕겨 흩어진 뒤 정면 가까이에 떨어진다. 각 물품을 들어 배치할 수 있다.
