# 기능 계약 — 급수·배수 시스템과 욕탕 물

## 문서 역할

이 문서는 급수·배수 시스템, 욕탕 수위, 손님의 욕탕 이용 조건과 실제 욕탕 체류시간에 관한 사용자 승인 기능을 아키텍처 단계에 전달한다.

이 문서가 정하는 것은 플레이어와 손님이 경험하는 동작, 조정 가능한 게임 값, 유지해야 할 기존 동작과 관찰 가능한 수용 결과뿐이다.

상태를 어디에 둘지, 어떤 클래스·Component·Subsystem·Interface를 사용할지, 어떤 API와 데이터 형식을 만들지, C++과 Blueprint가 무엇을 맡을지, 매 프레임 갱신·시간 기반 처리·알림·StateTree 연계를 어떤 방식으로 구현할지는 정하지 않는다. 이러한 설계는 아키텍처 에이전트가 현재 Source, 정본 문서와 Editor 사전 조사 결과를 근거로 독립적으로 결정한다.

## 기능 계약 상태

- `.md/QNA_FEATURE_SPEC.md`의 Q1~Q19 답변을 반영했다.
- 추가 Q20은 없다.
- 욕탕 미사용 또는 유효 욕탕 탐색 실패에 따른 만족도 감소는 폐기했다.
- 새로 기록할 시간은 손님이 욕탕 안에서 실제로 입욕한 누적 시간뿐이다.
- 본 문서는 기능 계약의 최종 사용자 확인 대상이다.

## 목적

플레이어가 각 욕탕의 급수밸브와 배수레버를 직접 조작해 물을 채우고 빼며, 수위를 손님이 입욕할 수 있는 상태로 관리하게 한다.

손님은 수위가 공통 임계치 이상인 욕탕만 존재하는 시설처럼 인식하고 이용한다. 임계치 미만인 욕탕은 탐색, 선택, 예약, 이동과 실제 입욕 판단에서 없는 욕탕과 똑같이 취급한다.

기존 60초 전체 입욕 단계와 별개로, 손님이 유효한 욕탕 안에서 실제로 입욕한 시간만 누적해 기록한다.

## 범위

이번 기능 범위에 포함한다.

- 욕탕별 급수밸브 열기와 닫기
- 욕탕별 배수레버 열기와 닫기
- 급수밸브와 배수레버의 회전 표현
- 급수 중 지정 물줄기 Niagara 표시
- 욕탕별 급수량과 배수량에 따른 0~100% 수위 변화
- 급수와 배수가 동시에 열렸을 때 순변화
- 수위에 따른 물 표면 표시
- 만수 시 급수 자동 닫힘
- 공통 80% 입욕 임계치
- 임계치에 따른 손님의 탐색, 선택, 예약, 이동, 입장, 체류와 퇴장
- 유효한 욕탕 탐색의 10초 제한시간
- 실제 욕탕 체류시간 누적
- 빈 욕탕의 회수와 재설치 결과
- 첫 욕탕 타입을 대상으로 한 전체 사용자 흐름 검증

## 기존 동작 유지

- 각 욕탕의 기존 이용 슬롯 수와 슬롯 예약 충돌 방지 동작을 유지한다.
- 사전 샤워 완료부터 시작하는 기존 60초 전체 입욕 단계 제한시간을 유지한다.
- 전체 입욕 단계의 시간에는 욕탕 탐색, 이동, 입장·퇴장 과정과 실제 체류가 모두 포함된다.
- 기존 규칙대로 knockdown 중에는 전체 입욕 단계 시간이 흐르지 않는다.
- 수건 부족 등 기존의 다른 만족도 규칙은 유지한다.
- 기존 설비 배치, 회수, 저장과 로드의 일반 계약은 이번 기능에서 요구한 물 관련 차이 외에는 바꾸지 않는다.
- 플레이어가 소지한 열쇠, 장비 또는 설비 아이템 때문에 급수·배수 조작이 막히지 않는다.

## 욕탕과 조작부의 관계

- 각 욕탕에는 그 욕탕 하나만 제어하는 급수밸브 하나와 배수레버 하나가 있다.
- 급수밸브는 같은 욕탕의 급수만 제어한다.
- 배수레버는 같은 욕탕의 배수만 제어한다.
- 한 욕탕의 조작이 다른 욕탕의 물이나 조작부 상태를 바꾸지 않는다.
- 급수밸브와 배수레버는 서로 독립적이다.
- 한쪽 조작부가 회전 중이어도 다른 쪽 조작부는 사용할 수 있다.

## 플레이어 상호작용

- 플레이어가 급수밸브 또는 배수레버를 바라보면 해당 조작부를 열거나 닫을 수 있다는 `E` 상호작용 안내를 확인할 수 있어야 한다.
- 현재 닫혀 있으면 안내는 여는 동작을, 현재 열려 있으면 닫는 동작을 구분할 수 있어야 한다.
- 플레이어가 안내가 표시된 조작부에 `E`를 누르면 그 조작이 시작된다.
- 조작이 받아들여지는 즉시 해당 급수 또는 배수 동작이 시작되거나 멈춘다.
- 조작부의 보이는 회전은 지정된 시간 동안 부드럽게 진행된다.
- 같은 조작부가 회전 중일 때 추가 `E` 입력은 받지 않는다.
- 회전 중인 같은 조작부를 다시 바라보면 `작동 중`임을 알 수 있어야 한다.
- 회전이 끝난 뒤에는 다시 반대 동작을 실행할 수 있다.
- 플레이어가 어떤 아이템을 들고 있어도 조작할 수 있다.
- 욕탕이 손님에게 예약됐거나 손님이 사용 중이어도 두 조작부를 모두 사용할 수 있다.

## 급수밸브 동작

### 열기

- 닫힌 자세에서 시계방향으로 열린 자세까지 회전한다.
- 조작이 받아들여지는 즉시 급수가 시작된다.
- 조작이 받아들여지는 즉시 그 욕탕에 지정된 물줄기 Niagara가 보인다.
- 급수밸브가 열려 있는 동안 해당 욕탕의 급수량이 적용된다.

### 닫기

- 현재 자세에서 원래 닫힌 자세로 반시계방향 회전한다.
- 조작이 받아들여지는 즉시 급수가 멈춘다.
- 조작이 받아들여지는 즉시 물줄기 Niagara가 보이지 않게 된다.
- 배수레버가 닫혀 있다면 닫는 순간의 물 양이 유지된다.
- 배수레버가 열려 있다면 급수만 멈추고 배수는 계속된다.

### 만수 자동 닫기

- 물이 100%에 도달하면 급수밸브는 자동으로 닫힌다.
- 자동 닫힘도 수동 닫기와 같은 반시계방향의 부드러운 회전으로 보인다.
- 급수와 물줄기 Niagara는 100% 도달 즉시 멈춘다.
- 자동 닫힘은 별도의 화면 알림을 띄우지 않는다.
- 배수레버의 열린 상태와 회전 상태는 자동 닫힘 때문에 바뀌지 않는다.

## 배수레버 동작

### 열기

- 닫힌 자세에서 시계방향으로 열린 자세까지 회전한다.
- 조작이 받아들여지는 즉시 배수가 시작된다.
- 배수레버가 열려 있는 동안 해당 욕탕의 배수량이 적용된다.

### 닫기

- 현재 자세에서 원래 닫힌 자세로 반시계방향 회전한다.
- 조작이 받아들여지는 즉시 배수가 멈춘다.
- 급수밸브가 닫혀 있다면 닫는 순간의 물 양이 유지된다.
- 급수밸브가 열려 있다면 배수만 멈추고 급수는 계속된다.

### 빈 욕탕에서의 열린 상태

- 물이 0%에 도달해도 배수레버는 자동으로 닫히지 않는다.
- 배수레버는 열린 자세를 유지하고 배수 동작도 열린 상태로 유지된다.
- 물 양만 0% 아래로 내려가지 않는다.
- 이후 급수가 시작되면 열려 있는 급수와 배수의 순변화를 계속 적용한다.

## 조작부 회전과 조정 기대

- 모든 회전은 각 조작부의 Editor에서 만들어 둔 닫힌 자세를 기준으로 한다.
- 급수밸브와 배수레버는 서로 다른 local 회전축, 열린 각도와 회전 시간을 가질 수 있다.
- 서로 다른 욕탕 종류마다 각 조작부의 local 회전축, 열린 각도와 회전 시간을 다르게 조정할 수 있어야 한다.
- 같은 욕탕 종류라도 Level에 놓인 개별 욕탕에서 이 값들을 덮어쓸 수 있어야 한다.
- 열린 방향은 기본적으로 닫힌 자세에서 바라본 시계방향이다.
- 닫힌 방향은 열린 자세에서 원래 닫힌 자세로 돌아가는 반시계방향이다.
- 조정값은 메시의 실제 pivot과 authored transform을 기준으로 원하는 회전 결과를 예측할 수 있어야 한다.
- 어떤 데이터 형식과 위치로 이 값을 제공할지는 이 문서에서 정하지 않는다.

## 물 양

- 각 욕탕은 다른 욕탕과 독립적인 현재 물 양을 가진다.
- 현재 물 양은 0%부터 100%까지로 표현한다.
- 0%는 완전히 빈 상태다.
- 100%는 완전히 찬 상태다.
- 물 양은 0%보다 작아지거나 100%보다 커지지 않는다.
- 새로 설치한 욕탕과 게임 시작 시 선배치된 욕탕은 모두 0%로 시작한다.
- 새로 설치한 욕탕과 게임 시작 시 선배치된 욕탕은 급수밸브와 배수레버가 모두 닫힌 상태로 시작한다.
- 손님의 입욕 자체는 물 양을 증가시키거나 감소시키지 않는다.
- 이번 범위에서 물 양을 바꾸는 것은 급수와 배수뿐이다.

## 급수량과 배수량

- 급수량과 배수량의 조정 단위는 초당 수위 퍼센트 포인트(`%/s`)다.
- 욕탕 종류마다 기본 급수량과 기본 배수량을 다르게 정할 수 있어야 한다.
- Level에 놓인 개별 욕탕마다 기본값을 덮어쓸 수 있어야 한다.
- 첫 욕탕 타입의 기본 결과는 빈 욕탕을 약 15초에 채우고 가득 찬 욕탕을 약 10초에 비우는 것이다.
- 위 결과에 대응하는 기본값은 급수 약 `6.6667%/s`, 배수 `10%/s`다.
- 기본 배수량은 기본 급수량보다 크다.
- 급수만 열려 있으면 급수량만큼 물이 증가한다.
- 배수만 열려 있으면 배수량만큼 물이 감소한다.
- 두 장치가 모두 닫혀 있으면 물 양은 유지된다.
- 두 장치가 모두 열려 있으면 같은 시간 동안 `급수량 - 배수량`의 순변화가 적용된다.
- 첫 욕탕 타입의 기본값으로 두 장치를 동시에 열면 수위는 초당 약 `3.3333` 퍼센트 포인트 감소한다.
- 개별 조정으로 급수량과 배수량의 대소 관계가 달라져도 같은 순변화 규칙을 적용한다.

## 물 표면 표시

- 욕탕의 물 양은 월드의 물 표면 높이로 확인할 수 있어야 한다.
- 0%에서는 물 표면이 보이지 않는다.
- 0%보다 크면 물 표면이 보인다.
- 0%와 100% 사이에서는 물 양 변화에 맞춰 물 표면이 끊김 없이 연속으로 오르내린다.
- 100%에서는 해당 욕탕에 정한 가득 찬 높이에 도달한다.
- 욕탕 종류별로 빈 위치와 가득 찬 위치를 실제 욕조 형태에 맞게 조정할 수 있어야 한다.
- Level에 놓인 개별 욕탕에서도 필요한 경우 이 표시 범위를 덮어쓸 수 있어야 한다.
- 현재 물 퍼센트를 숫자로 보여 주는 별도 HUD나 상호작용 안내는 추가하지 않는다.

## 물줄기 표시

- 각 욕탕은 급수 시 보여 줄 지정 Niagara System을 사용할 수 있어야 한다.
- 게임 시작과 새 설치 직후에는 물줄기가 보이지 않는다.
- 급수밸브 열기가 받아들여지는 즉시 물줄기가 보인다.
- 수동 닫기가 받아들여지거나 100% 도달로 자동 닫히는 즉시 물줄기가 보이지 않는다.
- 물줄기는 배수레버 상태 때문에 직접 켜지거나 꺼지지 않는다.
- 탕 종류가 늘어날 때 서로 다른 급수 표현을 지정할 수 있어야 한다.

## 손님이 인식하는 욕탕의 존재 조건

- 모든 욕탕은 공통 입욕 임계치 80%를 사용한다.
- 개별 욕탕이나 욕탕 종류마다 다른 입욕 임계치를 두지 않는다.
- 수위가 정확히 80%이면 손님이 이용할 수 있는 욕탕이다.
- 수위가 80% 미만이면 손님에게 그 욕탕은 없는 것과 같다.
- 이 존재 조건은 손님의 욕탕 탐색, 후보 비교, 선택, 슬롯 예약, 이동 지속, 실제 입장과 입욕 지속에 모두 적용된다.
- 수위가 80% 이상이어도 기존 슬롯 사용 가능 조건을 만족하지 못하면 이용할 수 없다.
- 수위가 80% 미만인 욕탕의 비어 있는 슬롯은 손님에게 후보가 아니다.

## 손님의 욕탕 루틴

### 최초 탐색

- 손님은 기존 사전 샤워를 마치면 60초 전체 입욕 단계에 들어간다.
- 손님은 수위 80% 이상이며 기존 슬롯 조건을 만족하는 욕탕만 찾는다.
- 수위 80% 미만인 욕탕은 탐색 결과에 없는 것처럼 무시한다.
- 유효한 욕탕과 슬롯을 확보하면 그 욕탕으로 이동한다.

### 예약 후 이동

- 이동 중에도 선택한 욕탕이 계속 80% 이상이어야 한다.
- 입장하기 직전에도 수위가 80% 이상이어야 한다.
- 예약 후 수위가 80% 미만이 되면 손님은 그 욕탕이 사라진 것처럼 기존 이동을 중단하고 그 욕탕을 이용하지 않는다.
- 더 이상 사용할 수 없는 예약은 다른 손님을 막지 않도록 해제된 결과가 보여야 한다.
- 전체 입욕 단계 시간이 남아 있으면 다른 유효한 욕탕을 새로 탐색한다.

### 입장과 체류

- 손님은 입장 시점에 수위가 80% 이상이고 기존 슬롯 조건도 유효한 경우에만 욕탕에 들어간다.
- 실제 입욕 중에도 욕탕 수위가 계속 80% 이상이어야 한다.
- 수위가 80% 이상인 동안에는 기존 입욕 행동을 계속한다.
- 손님이 들어 있는 사실 자체는 수위를 바꾸지 않는다.

### 체류 중 임계치 하락

- 사용 중인 욕탕의 수위가 80% 미만이 되는 즉시 그 욕탕은 안에 있는 모든 손님에게도 없는 욕탕이 된다.
- 해당 손님들은 현재 실제 욕탕 체류를 즉시 끝내고 욕탕에서 나온다.
- 퇴장 이후 전체 입욕 단계 시간이 남아 있으면 다른 유효한 욕탕을 탐색한다.
- 남은 전체 입욕 단계 시간이 없다면 기존 다음 단계로 진행한다.

### 전체 입욕 단계 종료

- 전체 입욕 단계는 사전 샤워 완료 후 시작한 기존 60초 범위를 넘지 않는다.
- 탐색, 이동, 입장·퇴장과 실제 입욕에 사용한 시간이 모두 이 60초 안에 포함된다.
- knockdown으로 기존 단계 시간이 멈춘 구간은 60초에서 진행되지 않는다.
- 60초가 끝나면 현재 탐색이나 욕탕 이용을 마치고 기존 다음 샤워 단계로 진행한다.

## 유효한 욕탕 탐색 제한시간

- 유효한 욕탕을 새로 찾아야 하는 각 탐색 구간의 제한시간은 최대 10초다.
- 최초 입욕 전 유효한 욕탕이 없을 때 10초 탐색 구간이 시작된다.
- 예약 또는 이동 중 욕탕 수위가 80% 미만이 되어 새 욕탕이 필요할 때도 새 10초 탐색 구간이 시작된다.
- 실제 입욕 중 수위가 80% 미만이 되어 나온 뒤 새 욕탕이 필요할 때도 새 10초 탐색 구간이 시작된다.
- 하나의 탐색 구간 안에서 후보를 반복 확인하는 것만으로 10초가 다시 시작되지는 않는다.
- 유효한 욕탕과 슬롯을 확보하면 현재 탐색 구간은 끝난다.
- 이후 새로운 원인으로 다시 욕탕을 찾아야 하면 새 탐색 구간으로 보고 최대 10초를 다시 부여한다.
- 전체 입욕 단계의 남은 시간이 10초보다 짧으면 탐색도 남은 전체 입욕 단계 시간까지만 가능하다.
- 탐색 제한시간이 먼저 끝나면 손님은 욕탕 이용을 포기하고 만족도 변화 없이 기존 다음 샤워 단계로 진행한다.
- 전체 입욕 단계 시간이 먼저 끝나도 같은 방식으로 다음 단계로 진행한다.

## 실제 욕탕 체류시간

- 각 손님에 대해 이번 전체 입욕 단계 동안의 실제 욕탕 체류시간을 별도로 기록한다.
- 실제 욕탕 체류시간은 손님이 유효한 욕탕 안에서 실제 입욕 행동을 하는 동안에만 증가한다.
- 욕탕을 탐색하는 시간은 포함하지 않는다.
- 욕탕으로 이동하는 시간은 포함하지 않는다.
- 욕탕에 들어가거나 나오는 전환 시간은 포함하지 않는다.
- 예약만 보유한 시간은 포함하지 않는다.
- knockdown 상태인 시간은 포함하지 않는다.
- 수위가 80% 미만이 되어 실제 입욕이 끝난 뒤의 시간은 포함하지 않는다.
- 한 손님이 여러 욕탕을 옮겨 다니면 각 욕탕에서 실제 입욕한 시간만 합산한다.
- 탐색 실패나 전체 단계 종료 전까지 실제 입욕하지 않았다면 기록값은 0초다.
- 탐색 실패 전에 실제 입욕한 적이 있다면 그때까지 누적한 시간은 보존한다.
- 이 기록은 만족도 계산에 사용하지 않는다.
- 이번 범위에서는 이 기록을 HUD에 표시하지 않는다.
- 이번 범위에서는 이 기록을 영구 저장 데이터로 만들 것을 요구하지 않는다.
- 어떤 값의 형태, 저장 위치와 외부 접근 방식을 사용할지는 아키텍처 단계에서 결정한다.

## 만족도 계약

- 유효한 욕탕을 찾지 못해 입욕하지 못해도 만족도를 낮추지 않는다.
- 탐색 제한시간이 끝나 다음 샤워 단계로 넘어가도 만족도를 낮추지 않는다.
- 실제 욕탕 체류시간이 짧거나 0초여도 이 기능 때문에 만족도를 낮추지 않는다.
- 수위가 80% 미만이 되어 욕탕에서 나온 경우에도 이 기능 때문에 만족도를 낮추지 않는다.
- 실제 욕탕 체류시간 자체는 이번 범위에서 만족도를 올리거나 내리지 않는다.
- 수건 부족처럼 기존의 다른 만족도 원인은 그대로 유지한다.

## knockdown 중 관찰 결과

- 기존 knockdown과 회복 흐름을 이 기능이 새로 정의하거나 교체하지 않는다.
- knockdown 상태인 동안 기존 60초 전체 입욕 단계 시간이 멈춘다.
- knockdown 상태인 동안 실제 욕탕 체류시간도 증가하지 않는다.
- 회복 뒤 욕탕 이용을 계속하려는 시점에는 현재 수위 80% 조건을 다시 만족해야 한다.
- 회복 시점에 수위가 80% 미만이면 그 욕탕은 없는 것처럼 취급하고, 남은 전체 입욕 단계 시간이 있으면 유효한 욕탕을 탐색한다.
- 회복 시점에 수위가 80% 이상이고 기존 이용 조건도 유지된다면 기존 손님 루틴이 허용하는 방식으로 입욕을 계속할 수 있다.

## 욕탕 회수와 재설치

### 회수 가능 조건

- 기존과 같이 욕탕의 모든 슬롯이 예약되지 않았고 사용 중이지 않아야 한다.
- 추가로 물 양이 정확히 0%여야 한다.
- 두 조건을 모두 만족해야 욕탕을 회수할 수 있다.
- 수위가 0%이고 모든 슬롯이 비어 있다면 급수밸브 또는 배수레버가 열려 있어도 회수를 시도할 수 있다.
- 수위가 0%보다 크면 다른 조건과 관계없이 회수할 수 없다.
- 예약 또는 사용 중인 슬롯이 하나라도 있으면 수위와 관계없이 회수할 수 없다.

### 회수 성공 결과

- 열린 급수밸브와 배수레버는 닫힌 상태가 된다.
- 보이던 물줄기 Niagara는 보이지 않게 된다.
- 욕탕은 기존 회수 흐름에 따라 월드에서 회수된다.
- 회수 아이템에는 물 양이나 열린 조작부 상태를 보존하지 않는다.

### 회수 실패 또는 중단 결과

- 회수 조건을 만족하지 않거나 회수가 완료되지 않았다면 욕탕은 월드에 그대로 남는다.
- 실패 또는 중단 전과 같은 수위, 조작부 외형, 물줄기 표시와 이용 가능성을 유지해야 한다.
- 이 결과를 실현하는 내부 복원 방식은 이 문서에서 정하지 않는다.

### 재설치 결과

- 회수한 욕탕을 다시 설치하면 물 양은 0%다.
- 급수밸브와 배수레버는 모두 닫혀 있다.
- 물 표면과 물줄기 Niagara는 보이지 않는다.
- 이전 설치에서의 물 양과 열린 조작부 상태는 복원하지 않는다.

## 관찰 가능한 수용 시나리오

### BH-WATER-001 — 빈 욕탕의 시작 상태

**Given** 새 게임의 선배치 욕탕 또는 새로 설치한 욕탕이 있다.
**When** 플레이어가 욕탕과 두 조작부를 확인한다.
**Then** 수위는 0%, 급수밸브와 배수레버는 닫힘이며 물 표면과 물줄기는 보이지 않는다.

### BH-WATER-002 — 급수밸브 열기

**Given** 수위가 100% 미만이고 급수밸브가 닫혀 있다.
**When** 플레이어가 급수밸브를 바라보고 `E`를 누른다.
**Then** 급수와 물줄기가 즉시 시작되고 밸브는 닫힌 자세에서 시계방향으로 부드럽게 열린다.

### BH-WATER-003 — 급수밸브 수동 닫기

**Given** 급수밸브가 열려 있고 물이 증가하고 있다.
**When** 플레이어가 급수밸브를 바라보고 `E`를 누른다.
**Then** 급수와 물줄기가 즉시 멈추고 밸브는 닫힌 자세로 반시계방향 회전한다.

### BH-WATER-004 — 배수레버 열기와 닫기

**Given** 욕탕에 물이 있고 배수레버가 닫혀 있다.
**When** 플레이어가 레버를 열면 배수가 즉시 시작되고, 회전 완료 뒤 다시 닫는다.
**Then** 레버는 열 때 시계방향, 닫을 때 반시계방향으로 부드럽게 움직이며 닫는 즉시 배수가 멈춘다.

### BH-WATER-005 — 같은 조작부의 회전 중 재입력

**Given** 급수밸브 또는 배수레버가 목표 자세로 회전 중이다.
**When** 플레이어가 같은 조작부를 다시 바라보고 `E`를 누른다.
**Then** `작동 중`임을 확인할 수 있고 현재 회전과 급수·배수 상태는 반대로 바뀌지 않는다.

### BH-WATER-006 — 두 조작부의 독립 사용

**Given** 한 조작부가 회전 중이다.
**When** 플레이어가 같은 욕탕의 다른 조작부에 `E`를 누른다.
**Then** 다른 조작은 정상적으로 받아들여지고 두 장치의 결과가 함께 적용된다.

### BH-WATER-007 — 기본 급수 시간

**Given** 첫 욕탕 타입이 0%이고 배수레버가 닫혀 있다.
**When** 기본 급수량으로 급수밸브를 계속 연다.
**Then** 수위는 연속으로 증가해 약 15초에 100%에 도달한다.

### BH-WATER-008 — 기본 배수 시간

**Given** 첫 욕탕 타입이 100%이고 급수밸브가 닫혀 있다.
**When** 기본 배수량으로 배수레버를 계속 연다.
**Then** 수위는 연속으로 감소해 약 10초에 0%에 도달한다.

### BH-WATER-009 — 동시 급수와 배수

**Given** 첫 욕탕 타입의 수위가 0%와 100% 사이에 있다.
**When** 급수밸브와 배수레버를 모두 연다.
**Then** 기본값에서는 초당 약 3.3333 퍼센트 포인트씩 수위가 감소하고 두 조작부의 열린 상태는 유지된다.

### BH-WATER-010 — 0% 하한

**Given** 배수레버가 열려 있고 수위가 0%에 도달한다.
**When** 배수가 계속되는 시간이 지난다.
**Then** 수위는 0%에 머물고 배수레버는 열린 자세를 유지한다.

### BH-WATER-011 — 100% 자동 닫힘

**Given** 급수밸브가 열려 있고 수위가 100%에 도달한다.
**When** 만수 상태가 된다.
**Then** 수위는 100%를 넘지 않고 급수와 물줄기가 즉시 멈추며 밸브는 반시계방향으로 부드럽게 닫힌다.

### BH-WATER-012 — 물 표면

**Given** 욕탕 수위가 0%, 중간 수위, 100%로 차례로 변한다.
**When** 플레이어가 욕탕을 관찰한다.
**Then** 0%에서는 물 표면이 숨겨지고 중간 구간에서는 연속으로 움직이며 100%에서는 정한 가득 찬 높이에 보인다.

### BH-WATER-013 — 80% 경계의 손님 후보

**Given** 슬롯 조건이 같은 두 욕탕의 수위가 각각 79.99%와 80%다.
**When** 손님이 이용 가능한 욕탕을 찾는다.
**Then** 79.99% 욕탕은 없는 것처럼 무시하고 80% 욕탕만 후보로 본다.

### BH-WATER-014 — 예약 후 수위 하락

**Given** 손님이 80% 이상 욕탕을 선택해 이동하고 있다.
**When** 입장 전에 수위가 80% 미만으로 내려간다.
**Then** 손님은 그 욕탕으로의 이용을 중단하고, 남은 전체 입욕 시간이 있으면 다른 유효한 욕탕을 탐색한다.

### BH-WATER-015 — 입장 직전 수위 확인

**Given** 손님이 예약한 욕탕의 입장 지점에 도착한다.
**When** 실제 입장 직전 수위가 80% 미만이다.
**Then** 손님은 욕탕에 들어가지 않고 그 욕탕을 없는 것처럼 취급한다.

### BH-WATER-016 — 사용 중 수위 하락

**Given** 한 명 이상의 손님이 같은 욕탕에서 실제 입욕 중이다.
**When** 플레이어의 배수 조작으로 수위가 80% 미만이 된다.
**Then** 그 욕탕을 사용 중인 모든 손님이 실제 체류를 즉시 끝내고 나오며, 시간이 남은 손님은 다른 유효한 욕탕을 탐색한다.

### BH-WATER-017 — 최초 탐색 제한시간 만료

**Given** 손님이 전체 입욕 단계에 들어갔지만 유효한 욕탕이 없다.
**When** 유효한 욕탕을 확보하지 못한 채 10초가 지나고 전체 입욕 단계 시간도 남아 있다.
**Then** 손님은 만족도 변화 없이 기존 다음 샤워 단계로 진행하고 실제 욕탕 체류시간은 0초다.

### BH-WATER-018 — 탐색 중 욕탕 준비

**Given** 손님이 유효한 욕탕을 찾은 지 10초가 지나지 않았다.
**When** 플레이어가 슬롯이 빈 욕탕을 80% 이상으로 채운다.
**Then** 손님은 그 욕탕을 새 후보로 인식하고 기존 슬롯 조건을 만족하면 이용할 수 있다.

### BH-WATER-019 — 재탐색 제한시간

**Given** 손님이 실제 입욕하다 수위 하락으로 나왔고 전체 입욕 시간이 10초보다 많이 남아 있다.
**When** 새 유효 욕탕을 찾아야 한다.
**Then** 새 탐색 구간에 최대 10초가 주어지며 같은 구간의 반복 확인만으로 그 시간이 다시 시작되지는 않는다.

### BH-WATER-020 — 전체 입욕 시간에 의한 탐색 상한

**Given** 새 탐색이 필요하지만 전체 입욕 단계 시간이 4초 남아 있다.
**When** 유효한 욕탕을 찾지 못한다.
**Then** 탐색은 최대 4초만 계속되고 전체 단계 종료와 함께 기존 다음 샤워 단계로 진행한다.

### BH-WATER-021 — 실제 욕탕 체류시간만 누적

**Given** 한 손님이 탐색, 이동, 입장, 실제 입욕, 퇴장 과정을 거친다.
**When** 전체 입욕 단계가 끝난다.
**Then** 기록된 실제 욕탕 체류시간에는 실제 입욕 구간만 포함되고 나머지 구간은 포함되지 않는다.

### BH-WATER-022 — 여러 욕탕의 체류시간 합산

**Given** 한 손님이 첫 욕탕에서 입욕하다 수위 하락으로 나온 뒤 두 번째 욕탕에서 다시 입욕한다.
**When** 전체 입욕 단계가 끝난다.
**Then** 두 욕탕에서 실제 입욕한 시간만 하나의 실제 욕탕 체류시간으로 합산된다.

### BH-WATER-023 — 탐색 실패와 만족도

**Given** 손님이 일부 시간 실제 입욕한 뒤 재탐색에 실패한다.
**When** 탐색 제한시간이 끝나 다음 샤워 단계로 진행한다.
**Then** 그때까지의 실제 욕탕 체류시간은 보존되고 욕탕 미사용 또는 탐색 실패를 이유로 만족도가 바뀌지 않는다.

### BH-WATER-024 — knockdown 시간 제외

**Given** 손님이 전체 입욕 단계 도중 knockdown 된다.
**When** knockdown 상태가 유지됐다가 회복한다.
**Then** 해당 구간은 전체 입욕 단계 시간과 실제 욕탕 체류시간 모두에 더해지지 않고, 회복 뒤 현재 수위 조건을 다시 적용한다.

### BH-WATER-025 — 사용 중 플레이어 조작

**Given** 손님이 욕탕을 예약했거나 실제 사용 중이고 플레이어가 아이템을 들고 있다.
**When** 플레이어가 급수밸브 또는 배수레버에 `E`를 누른다.
**Then** 조작은 정상적으로 실행되며 이후 손님 행동은 실제 수위와 80% 조건을 따른다.

### BH-WATER-026 — 열린 조작부가 있는 빈 욕탕 회수

**Given** 모든 슬롯이 비어 있고 수위가 0%지만 하나 이상의 조작부가 열려 있다.
**When** 플레이어가 욕탕 회수를 성공시킨다.
**Then** 조작부와 물줄기가 닫힌 결과를 보이고 욕탕이 회수되며 이전 물·조작 상태는 회수 아이템에 남지 않는다.

### BH-WATER-027 — 물이 남은 욕탕 회수 거부

**Given** 모든 슬롯은 비어 있지만 수위가 0%보다 크다.
**When** 플레이어가 욕탕 회수를 시도한다.
**Then** 욕탕은 회수되지 않고 기존 수위, 조작부 외형, 물줄기 표시와 이용 가능성이 유지된다.

### BH-WATER-028 — 사용 중 욕탕 회수 거부

**Given** 수위가 0%지만 하나 이상의 슬롯이 예약됐거나 사용 중이다.
**When** 플레이어가 욕탕 회수를 시도한다.
**Then** 욕탕은 회수되지 않고 기존 상태와 손님 이용 흐름이 유지된다.

### BH-WATER-029 — 회수 후 재설치

**Given** 이전 설치에서 물이나 열린 조작부 상태가 있었던 욕탕을 회수했다.
**When** 플레이어가 그 욕탕을 다시 설치한다.
**Then** 새 설치는 0%, 두 조작부 닫힘, 물 표면과 물줄기 숨김 상태로 시작한다.

## 수직 구현 요구

이 기능은 입력, 월드 피드백, 시간에 따른 수위, Niagara, 조작부 회전, 손님 루틴, 회수와 Editor authoring이 함께 맞아야 하므로 첫 욕탕 타입 하나의 전체 흐름을 먼저 검증한다.

대표 흐름은 다음 사용자 결과를 처음부터 끝까지 포함한다.

1. 빈 욕탕을 확인한다.
2. 급수밸브를 열어 물줄기와 수위 증가를 확인한다.
3. 80%에 도달한 욕탕을 손님이 후보로 인식하고 입욕한다.
4. 사용 중 배수레버를 열어 수위를 80% 미만으로 내린다.
5. 손님이 즉시 나오고 새 유효 욕탕을 찾는다.
6. 실제 입욕 시간만 누적됐고 만족도는 변하지 않았음을 확인한다.
7. 물을 0%로 만든 뒤 욕탕을 회수하고 재설치해 빈 상태를 확인한다.

첫 욕탕 타입의 이 흐름을 사용자 확인 없이 다른 탕 종류로 일반화하지 않는다.

## 비목표

이번 기능에서 요구하지 않는다.

- 물 온도, 오염도, 청결도와 약품
- 손님 수에 따른 수위 감소나 물 소비
- 넘침, 누수, 증발과 물리 유체 시뮬레이션
- 배수 물줄기, 배수구 시각효과와 추가 사운드
- 현재 수위 숫자 HUD
- 욕탕별 또는 탕 종류별 입욕 임계치
- 욕탕 미사용, 탐색 실패 또는 실제 체류시간에 따른 만족도 변화
- 실제 욕탕 체류시간의 SaveGame 영구 저장
- 네트워크 복제 정책
- 기존 knockdown 흐름의 재설계
- 첫 욕탕 타입 검증 전 다른 모든 탕 종류의 확장

## 아키텍처 에이전트의 독점 설계 영역

아키텍처 에이전트는 위 기능 계약을 바꾸지 않는 범위에서 구현 구조를 자유롭게 설계한다. 다음 항목에는 이 문서가 답을 제시하거나 후보를 제한하지 않는다.

- 물, 조작부, 손님 이용 가능성과 체류시간의 상태 소유 위치
- 클래스, Component, Subsystem, Interface와 함수 구성
- 데이터 표현, 저장 수명과 접근 방식
- C++과 Blueprint의 책임 경계
- 시간에 따른 수위·회전·탐색·체류시간 처리 방식
- 손님 행동이 수위 변화를 인식하는 방식
- 기존 StateTree와 손님 루틴의 연계 방식
- 회수 성공·실패·중단을 안전하게 처리하는 내부 방식
- 선배치·신규 설치·기존 저장 데이터의 호환 방식
- 실제로 수정하거나 추가할 파일과 asset 목록

설계 결과는 이 문서의 모든 관찰 가능한 시나리오를 만족해야 하며, 기능 변경이 필요하면 설계에서 임의로 결정하지 말고 기능 명세 단계로 되돌린다.
