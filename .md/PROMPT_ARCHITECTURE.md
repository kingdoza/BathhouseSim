# 설계 입력 — 들고 있는 물건 조작 LMB 통일

## 목적과 상태

들고 있는 물건으로 조준 대상에 하는 일을 월드 상호작용 키(E/F)에서 LMB·RMB로 옮긴다. 앞으로 늘어날 "박스 → 진열대" 작업(음료, 화장대, 샤워 비품 등)이 같은 조작을 쓰도록, 기존 삽과 수건바구니 조작부터 바꾼다.

- 2026-09-28 새 작업. 사용자 선택 정본: [QNA_FEATURE_SPEC.md](QNA_FEATURE_SPEC.md) 사용자 지정 사항, 통일 규칙, 질문 없이 적용할 전제와 Q1~Q7. 전체 답변 완료, 미확정 사용자 선택 없음.
- 이 기능 계약은 사용자 승인 대기 상태다. 승인 전에는 아키텍처·구현 단계로 넘기지 않는다.
- 이 파일의 이전 내용(상점 확장과 개봉 물품 흩어짐)은 커밋 `578ef1f`에 있으며, 이 작업의 설계 입력으로 전면 교체했다.
- 서비스 품목(음료 냉장고·화장대) QNA는 `.md/NextWork/QNA_FEATURE_SPEC.md`에 따로 있고 이 작업의 입력이 아니다. 이 작업이 끝난 뒤 그쪽을 이 규칙에 맞춰 고친다.

이 문서는 플레이어 입력, 월드·화면 결과, 실패 경로, Editor 조정값과 수용 기준을 정한다. 클래스, 입력 연결 구조, 연속 옮기기의 실행 방식, HUD 구성 방식과 파일 구성은 설계 단계가 결정한다.

## 통일 규칙

> **들고 있는 물건으로 대상에 하는 일은 LMB, 그 반대 방향은 RMB. 손으로 하는 일은 E. 내려놓기는 G.**
> LMB는 들고 있는 물건의 효과이며, 조준 대상과 들고 있는 물건의 상태에 따라 결과가 달라질 수 있다.

"손으로 하는 일"에는 물건 종류와 상관없이 손에 든 것을 어딘가에 두는 동작도 포함한다(Q1 A).

## 현재와 목표

근거는 현재 정본 문서와 Source다. 이번 명세를 위해 Editor·PIE를 새로 조사하지 않았다.

| 대상 | 현재 | 목표 |
|---|---|---|
| 삽: 퍼담기·반환·투입 | E 단발. 조준 대상과 삽 내용물로 행동 하나 결정 | LMB 단발. 같은 행동 표 |
| 수건바구니 → 선반·대기 기계 | E 1장, F 들어갈 만큼 | LMB 1장, 누르고 있으면 연속 |
| 사용 수건통·완료 기계 → 수건바구니 | E 1장, F 들어갈 만큼 | RMB 1장, 누르고 있으면 연속 |
| 바닥 사용한 수건 줍기 | E 한 장씩 | RMB 한 장씩 |
| 거치대 보관·키 걸이 반납·쓰레기통 | E | E 그대로 |
| F | 수건 "가능한 만큼" 옮기기 | 들고 있는 물건 조작에 쓰지 않음 |
| RMB | 사용처 없음(Source·정본 검색 기준) | 들고 있는 물건의 반대 방향 동작 |

사전조사 생략 근거: 이번 변경의 결과는 기존 이동 규칙과 새 키 배정으로 정해지며 기존 asset 값에 좌우되지 않는다. 다만 실제 입력 매핑 asset(`IMC_FirstPerson` 등)에 RMB가 이미 다른 동작으로 연결돼 있는지는 문서로 확인되지 않았다. 설계·Editor 단계에서 확인하고, 이미 쓰이고 있으면 이 기능 명세로 돌아온다.

## 질문 없이 적용할 전제

- **이동 가능한 방향과 조건은 바꾸지 않는다.** 어떤 대상과 어느 방향으로 옮길 수 있는지, 정원·수건 상태 조건, 실패 이유는 지금 규칙 그대로이고 누르는 키만 바뀐다. 예: 대기 상태 세탁기에 넣은 수건을 빼는 경로는 여전히 없다.
- 이미 LMB인 동작은 그대로다: 몽키스패너 휘두르기(대상 무관), 대걸레 닦기, 배송 상자 개봉, 설비 아이템 배치 확정.
- 컴퓨터·배치 모드가 LMB를 먼저 쓰는 우선순위는 그대로다.
- 빈손으로 하는 일은 E 그대로다: 물건 집기, 컴퓨터 진입, 순환기 레버, 욕탕 급수·배수 조작, 세탁기·건조기 작동 시작, 현금 받기, 키 걸이에서 키 가져가기, 거치대에서 꺼내기.
- G 내려놓기, Q Hold 설비 회수, ESC 컴퓨터 나가기는 그대로다.
- 보일러·쿨러 투입구 문 자동 열림 조건은 바뀌지 않는다. 안내 키만 LMB로 바뀐다.

## 삽

| 삽 상태 | 조준 대상 | LMB 결과 |
|---|---|---|
| 빈 삽 | 석탄 또는 드라이아이스 공급함 | 해당 재료 한 삽 퍼담기 |
| 빈 삽 | 보일러·쿨러 투입구 | 거부, 빈 삽 안내 |
| 재료가 든 삽 | 같은 재료 공급함 | 전량 반환, 삽 비움 |
| 재료가 든 삽 | 다른 재료 공급함 | 거부, 삽 내용 보존 |
| 석탄 삽 / 드라이아이스 삽 | 보일러 / 쿨러 투입구 | 기존 투입 규칙대로 투입(초과분 폐기, 가득 참·회수 중 거부 포함) |
| 드라이아이스 삽 / 석탄 삽 | 보일러 / 쿨러 투입구 | 거부, 재료 불일치 안내 |
| 빈 삽 또는 재료가 든 삽 | 그 밖의 곳, 아무것도 없음 | 아무 일도 없음. 휘두르기 없음 |

- LMB 한 번에 행동 하나. 누르고 있어도 반복하지 않고, 퍼담기 직후 같은 입력으로 반환까지 이어지지 않는다.
- 삽을 든 채 RMB, F는 아무 일도 하지 않는다.
- 삽을 든 채 공급함·투입구를 조준하고 E를 눌러도 퍼담기·반환·투입은 일어나지 않는다.
- 삽을 든 채 삽 거치대에 E를 누르면 지금처럼 보관된다. 재료는 보존된다.
- 투입구 문은 지금처럼 투입 가능한 조준 동안 열리고, 안내 키만 LMB로 바뀐다.

## 수건바구니

### 방향과 대상

| 조준 대상과 상태 | LMB (바구니 → 대상) | RMB (대상 → 바구니) |
|---|---|---|
| 수건 선반 | 깨끗한 수건 넣기 | 없음 |
| 대기 세탁기 | 사용한 수건 넣기 | 없음 |
| 완료 세탁기 | 없음 | 젖은 수건 빼기 |
| 대기 건조기 | 젖은 수건 넣기 | 없음 |
| 완료 건조기 | 없음 | 깨끗한 수건 빼기 |
| 사용 수건통 | 없음 | 사용한 수건 빼기 |
| 바닥의 사용한 수건 | 없음 | 한 장 줍기 |
| 작동 중인 세탁기·건조기 | 없음 | 없음 |

- 표의 "없음"은 지금도 불가능한 방향이다. 그 키를 누르면 아무것도 옮기지 않고 HUD에 이유를 보인다.
- 바구니에는 같은 상태의 수건만 들어간다. 빈 바구니는 처음 들어온 수건의 상태가 되고, 다시 비면 상태가 풀린다(기존 규칙).
- 상태가 맞지 않는 수건, 바구니 가득 참, 대상 가득 참, 대상 빔은 옮기지 않고 이유를 보인다.
- 수건바구니를 든 채 E·F로 선반·기계·수건통·바닥 수건에 수건을 옮기는 경로는 없다.
- 수건바구니를 든 채 거치대에 E를 누르면 지금처럼 보관된다. 수건 수량은 보존된다.
- 수건바구니를 든 채 수건 대상이 아닌 곳에 LMB·RMB를 누르면 아무 일도 없다.

### 연속 옮기기

- LMB·RMB를 누르는 순간 1장을 옮긴다.
- 계속 누르고 있으면 기본 0.15초 간격(조정 가능)으로 1장씩 이어서 옮긴다.
- 다음 중 하나가 생기면 멈춘다: 바구니가 가득 참 또는 빔, 대상이 가득 참 또는 빔, 대상 상태가 바뀌어 그 방향이 불가능해짐, 조준이 그 대상에서 벗어남, 키를 뗌.
- 조준이 벗어나 멈춘 뒤에는 누른 채로 다른 대상이나 같은 대상을 다시 조준해도 자동으로 다시 시작하지 않는다. 떼었다가 다시 눌러야 한다.
- 바닥 사용한 수건은 한 장이 대상 하나라서 한 장을 주우면 그 대상이 사라지므로 멈춘다.
- 연속 옮기기 도중 컴퓨터 진입, 배치 모드 진입, 바구니 내려놓기·거치가 일어나면 멈춘다.
- 이미 옮긴 수건은 되돌리지 않는다. 각 한 장 이동은 기존처럼 완전히 성공하거나 아무 변화가 없다.

## HUD 안내

- 조준 대상과 들고 있는 물건으로 가능한 동작을 키별로 함께 표시한다. 예: 수건 선반 앞 깨끗한 바구니 — "LMB 넣기", 완료 세탁기 앞 빈 바구니 — "RMB 빼기".
- 한 대상에서 LMB·RMB가 모두 의미 있는 경우 둘 다 표시하고, 할 수 없는 쪽은 짧은 이유를 표시한다. 예: "바구니 가득 참", "완료 후 뺄 수 있음", "다른 상태의 수건".
- 삽은 가능한 LMB 행동 하나를 표시한다. 예: "LMB 퍼담기", "LMB 투입". RMB는 표시하지 않는다.
- E로 하는 보관·반납·버리기는 지금처럼 E로 안내한다.
- F 안내는 들고 있는 물건 조작에서 사라진다.
- 세부 배치·모양은 이후 UI 작업에서 정한다. 이번에는 키와 동작이 헷갈리지 않게 읽혀야 한다.

## 기존 기능 유지 범위

- 삽의 재료 규칙, 초과분 폐기, 가득 참·회수 중 거부, 투입구 문 자동 열림, 설비 노동 가동 전체
- 수건의 상태 전환, 기계 대기·작동·완료, 정원, 손님 수건 사용·반납, 수건 선반 표현
- 몽키스패너·대걸레·배송 상자의 LMB, 설비 배치 LMB 확정과 우선순위
- 거치대·키 걸이·쓰레기통 E, 컴퓨터 E·ESC, 순환기 레버 E, G 내려놓기, Q Hold 회수
- 관련 없는 기존 결함을 포괄적으로 수정하는 작업으로 확대하지 않는다.

## Editor authoring 기대

- 연속 옮기기 간격을 조정할 수 있어야 한다. 단위는 초, 기본 0.15.
- RMB를 새 입력으로 연결한다. 기존 입력 매핑과 충돌하지 않아야 하며, 충돌하면 기능 명세로 돌아온다.
- HUD가 LMB·RMB 동작과 이유를 표시할 수 있어야 한다.

## 단계 판단

이동 규칙은 그대로이고 키 배정과 연속 옮기기만 바뀌므로 수직 구현을 따로 두지 않고 한 단계에서 완성한다(Q7 A). 연속 옮기기 간격은 PIE에서 실제 감각을 보고 조정한다.

대표 시나리오: 빈 바구니를 들고 사용 수건통을 조준해 RMB를 누르고 있으면 수건이 0.15초마다 한 장씩 바구니로 들어오다가 통이 비면 멈춘다. 대기 세탁기를 조준해 LMB를 누르고 있으면 한 장씩 들어가다가 정원이 차면 멈춘다. 삽을 들고 석탄 공급함에 LMB를 누르면 퍼담고, 보일러 투입구에 LMB를 누르면 투입된다.

## 관찰 가능한 수용 시나리오

| ID | Given | When | Then |
|---|---|---|---|
| CTRL-001 | 빈 삽, 석탄 공급함 조준 | LMB | 석탄 한 삽 퍼담기 |

| CTRL-003 | 석탄 삽, 투입 가능한 보일러 투입구 조준 | 조준 후 LMB | 문 열림 안내가 LMB로 표시, LMB로 투입, 기존 초과분·가득 참 규칙 유지 |
| CTRL-004 | 드라이아이스 삽, 보일러 투입구 조준 | LMB | 거부, 재료 불일치 안내, 삽 내용 보존 |
| CTRL-005 | 빈 삽, 석탄 공급함 조준 | LMB를 누른 채 유지 | 한 번만 퍼담기, 이어서 반환되지 않음 |

## 비목표와 설계 자유 영역

- 이동 가능한 방향·조건의 변경(예: 대기 기계에서 수건 빼기, 선반에서 수건 꺼내기)
- F의 새 용도, 키 재설정 UI
- 몽키스패너·대걸레·배송 상자의 RMB 동작
- 음료 냉장고·화장대 등 서비스 품목(`.md/NextWork/`에서 별도 진행)
- HUD 세부 레이아웃 디자인 확정
- 저장·불러오기, 멀티플레이

설계 단계는 기존 정본·Source를 근거로 RMB 입력 연결, LMB·RMB와 기존 장비 사용·E/F 상호작용 경로의 관계, 연속 옮기기 실행 방식, 조준 이탈 판정, HUD 표시 데이터와 검증 방법을 독립적으로 결정한다. 설계 결과는 [AGENT_ARCHITECTURE.md](AGENT_ARCHITECTURE.md)의 소유권·산출물 규칙을 따른다. 이 기능 입력 작성만으로 Source·Content 구현이나 Editor 수정을 시작하지 않는다.
