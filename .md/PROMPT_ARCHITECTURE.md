# 설계 입력 — 설비 노동 가동과 원형 계기

## 목적과 상태

> 2026-09-25 변경 반영: 삽 퍼담기·반환·투입을 E 단발로 통일하고, 보일러의 별도 계기판 메시 필수 조건을 해제하며, 투입 가능한 조준 중 보일러 투입구 문이 자동으로 열린다. 사용자 지정 사항과 QNA Q48~Q53 답변을 반영했고 미확정 사용자 선택은 없다. 이 변경분은 사용자 승인 대기 상태다.

플레이어가 보일러에 석탄, 쿨러에 드라이아이스를 삽으로 공급하고 순환기의 레버를 조작해 설비를 가동한다. 설비별 남은 가동수치를 월드 원형 계기의 바늘로 읽고, 소진 전에 노동을 수행하는 관리 흐름을 만든다.

- 사용자 요청에 따라 기존 파일 내용을 이 작업의 설계 입력으로 전면 교체했다.
- 사용자 선택 정본: [QNA_FEATURE_SPEC.md](QNA_FEATURE_SPEC.md) Q29~Q53과 2026-09-25 사용자 지정 사항. 전체 답변 완료, 미확정 사용자 선택 없음. 2026-09-25 지정은 Q35의 LMB와 Q38의 F 반환보다 우선한다.
- 현재 상태: 사전조사 반영 및 설계 입력 작성 완료. 이번 교체본의 최종 승인 여부는 이전 물 관리 계약 승인과 구분한다.
- 2026-09-25 변경은 아직 사용자 수직 승인을 받지 않은 보일러 수직 구현 범위를 수정한다. 이미 구현·authoring된 LMB/F 삽 작업과 계기판 메시 필수 검사는 목표가 아니라 바꿀 현재 상태다.
- 사전조사 근거: [REPORT_UNREAL_DISCOVERY.md](REPORT_UNREAL_DISCOVERY.md), 2026-09-23, UE 5.8.3.
- 이전 Q1~Q28은 기존 물 관리의 유지 계약이다. 이번 확장은 항시 가동 전제를 노동 가동으로 대체하며 물의 수온·오염 계산 자체는 유지한다.
- Q32 A는 추후 변경을 고려한 이번 최소 기능 범위다. 자동 설정 축소, 비례 배분, 욕탕 우선순위는 만들지 않는다.
- 첫 설계·수직 구현 대상은 보일러다. 쿨러·수동 순환기의 최종 요구도 명시하지만, 첫 수직 구현 사용자 승인 전에 전체 확장하지 않는다.

이 문서는 플레이어 입력, 월드 결과, 실패·취소, Editor 조정값과 수용 기준을 정한다. 클래스, 상태 소유자, 데이터 구조, API, 실행 방식과 구현 파일 구성은 설계 단계가 결정한다.

## 용어와 기본값

- 정격 용량: 설비 인스턴스가 가동 중일 때 제공하는 순환·가열·냉각 용량 포인트.
- 가동수치: 해당 설비에 남은 재료 또는 노동의 축적량. 정격 용량과 별개다.
- 설치용량: 정상 설치된 해당 종류 설비들의 정격 합. 비가동 설비도 포함한다.
- 가동용량: 정상 설치되고 가동수치가 양수인 해당 종류 설비들의 정격 합.
- 예약량: 기존 욕탕 설정에서 계산된 해당 종류 요구량 합.
- 계기는 게임 가동수치를 보여주는 압력계 형태의 장치이며 실제 압력 시뮬레이션을 요구하지 않는다.

| 값 | 기본값 | 단위·범위 |
|---|---:|---|
| 종류별 정격 용량 | 100 | 용량 포인트, 기존 인스턴스별 조정 유지 |
| 종류별 최대 가동수치 | 100 | 가동 포인트, 양수 |
| 신규 설치 가동수치 | 0 | 선배치 신규 시작 포함 |
| 종류별 자연 감소 | 1 | 가동 포인트/초 |
| 석탄·드라이아이스 한 삽 | 25 | 가동 포인트 |
| 순환기 한 왕복 시간 | 1 | 초 |
| 한 왕복 완료 증가량 | 10 | 가동 포인트 |
| 가동 바늘 시작 비율 | 1/3 | 전체 0~최대 회전 범위 중 비율 |
| 보일러 투입구 문 열기·닫기 시간 | 각 0.2 | 초 |

시간은 플레이 중 진행되는 게임 시간을 기준으로 한다. 컴퓨터를 사용해도 월드 시간이 흐른다. 별도 현실시간 경과·오프라인 소모는 요구하지 않는다.

## 설비 가동과 자연 감소

- 신규 설치·새 Level의 선배치 설비는 가동수치 0, 바늘 0, 제공 가동용량 0으로 시작한다.
- 잔량이 보존된 회수 아이템의 재설치는 신규 설치와 구분하고 보존값으로 재개한다.
- 가동수치는 0~해당 설비 최대값에 머문다.
- 양수가 되는 즉시 가동 상태로 전환하고 정격 전부를 제공한다. 잔량 비율로 출력을 낮추지 않는다.
- 설치된 설비는 양수인 동안 종류별 일정 속도로 감소한다. 실제 욕탕 사용, 예약량, 컴퓨터 조작, 노동 중 여부에 따라 감소를 멈추지 않는다.
- 0에 도달하면 비가동으로 바뀌고 해당 설비의 가동용량 기여만 0이 된다. 설치용량은 유지한다.
- 별도 점화, 전원 스위치, 연료 연소 지연, 드라이아이스 승화 계산은 없다.
- 최대 100을 채운 뒤 추가 투입 없이 기본 100초 가동한다.
- 예비 잔량을 물리 압력, 물의 양 또는 기존 욕탕 순환도와 동일 값으로 취급하지 않는다.

## 공용 삽과 공급함

- 석탄 공급함과 드라이아이스 공급함을 월드에 각각 둔다. 이번 범위의 공급량은 무제한이다.
- 공급함의 구매·재보충·운반 시스템과 플레이어 배치 기능은 이번에 추가하지 않는다.
- 삽은 기존 한 개 물리 도구 소지 흐름을 따른다. E로 집기·지정 거치대 보관/회수, G로 내려놓기를 지원한다.
- 한 삽은 빈 상태 또는 석탄/드라이아이스 한 종류 한 회분을 갖는다. 섞기·추가 퍼담기는 없다.
- 들고 있는 삽과 내려놓은 삽 모두 빈 상태와 재료 종류를 구분할 수 있게 표현한다.
- 삽의 재료는 내려놓거나 거치해도 유지되며 시간에 따라 소실되지 않는다.
- 보유 도구가 삽이 아니거나 필요한 대상·거리·시선 조건을 충족하지 못하면 삽 작업을 실행하지 않는다.
- 실제 조준 대상인 공급함/투입구가 작업 대상이다. 벽 너머 또는 범위 밖 대상에 재료를 전달하지 않는다.

### E 행동 결정

삽의 월드 작업은 모두 E 단발 입력이다. 조준 대상과 삽 내용물로 실행할 행동이 하나로 정해지며 HUD는 그 행동 하나만 안내한다.

| 삽 상태 | 조준 대상 | E 결과 |
|---|---|---|
| 빈 삽 | 재료 공급함 | 해당 재료 한 삽 퍼담기 |
| 빈 삽 | 설비 투입구 | 실행 거부, 빈 삽 안내 |
| 재료가 든 삽 | 같은 재료 공급함 | 전량 반환, 삽 비움 |
| 재료가 든 삽 | 다른 재료 공급함 | 거부, 삽 내용 보존 |
| 재료가 든 삽 | 해당 재료를 받는 설비 투입구 | 아래 투입 규칙에 따라 투입 |
| 재료가 든 삽 | 해당 재료를 받지 않는 설비 투입구 | 거부, 삽 내용 보존 |
| 빈 삽 또는 재료가 든 삽 | 삽 지정 거치대 | 기존 거치 보관, 재료 보존 |

- E 한 번은 한 행동만 실행한다. 누르고 있어도 반복하지 않고, 퍼담기 직후 같은 입력으로 반환까지 이어지지 않는다.
- LMB와 F는 삽 퍼담기·반환·투입을 실행하지 않는다. 삽 자유 휘두르기는 추가하지 않는다.
- 삽 E 집기, 지정 거치대 E 보관/회수, G 내려놓기와 빈손·다른 도구의 기존 입력은 유지한다.

### 퍼담기

1. 빈 삽을 든 채 해당 공급함을 조준한다.
2. E 한 번으로 즉시 해당 재료 25포인트를 삽에 담는다.
3. 삽 내용물 표현과 다음 가능한 행동 안내가 즉시 갱신된다.

Hold, 작업 진행률, 1초 대기, 애니메이션 종료 조건은 없다. 누르고 있어도 자동 반복되지 않는다. 재료가 든 삽에는 추가로 퍼담지 않는다. 같은 재료 공급함에서의 E는 반환, 다른 재료 공급함에서의 E는 거부이며 삽이 25를 넘게 담는 경우는 없다.

### 투입

- 보일러는 석탄만, 쿨러는 드라이아이스만 받는다.
- 해당 설비가 정상 설치 상태이고 회수 중이 아니며 가동수치가 최대 미만이면, 올바른 재료를 든 삽으로 투입구를 조준해 E를 누른다. 보일러는 이 조건을 만족하는 조준 동안 투입구 문이 열려 있다.
- 투입 성공 시 한 삽 전체를 소비하고 설비 가동수치는 최대값까지 증가한다. 초과분은 폐기하며 삽에 남기지 않는다.
- 예: 설비 90, 삽 25이면 E 직후 설비 100, 삽 빈 상태다. 초과 15는 버린다.
- E 시점에 이미 최대값이면 투입을 거부하고 삽을 비우지 않는다. 자연 감소로 조금이라도 공간이 생긴 뒤의 E 투입은 초과분 폐기 규칙을 따른다.
- 빈 삽·잘못된 재료·대상 소실·회수 중·가득 참 등 실패에서는 재료 이동이나 가동수치 증가가 없다.
- 성공 뒤 입력을 놓거나 시선이 벗어나도 즉시 완료한 투입은 되돌리지 않는다.
- 삽의 순간적인 장식 동작을 추가하더라도 입력 성공이나 용량 활성화를 그 동작 완료까지 지연하지 않는다.

### 반환

- 재료가 있는 삽으로 종류가 일치하는 공급함을 조준하고 E를 누르면 전량 반환하고 삽을 비운다.
- 공급함은 무제한이므로 별도 유한 재고를 계산하지 않는다.
- 다른 재료 공급함에는 반환할 수 없고 기존 내용을 보존한다.
- 반환 자체로 어떤 설비의 가동수치도 올라가지 않는다.

## 보일러 투입구 문 자동 열림

보일러 투입구에는 별도 회전 피벗을 중심으로 회전하는 문이 있다. 별도 열기 키는 없다.

### 열림 조건

다음을 모두 만족하는 동안 문은 열림 자세를 목표로 움직인다.

- 플레이어가 석탄이 든 삽을 들고 있다.
- 해당 보일러 투입구를 투입 가능한 거리·시선으로 조준하고 있다.
- 보일러가 정상 설치 상태이고 회수 중이 아니다.
- 가동수치가 최대 미만이다.

문이 열려 있다는 것은 지금 E를 누르면 투입된다는 뜻이다. 하나라도 잃으면 닫힘 자세를 목표로 움직인다.

- 빈 삽, 드라이아이스가 든 삽, 빈손 또는 다른 도구로 조준하면 열리지 않는다.
- 가득 찬 보일러는 조준 중에도 닫혀 있고 가득 참을 안내한다. 계속 조준하는 동안 자연 감소로 공간이 생기면 자동으로 열린다.
- 조준만으로 재료를 소비하거나 가동수치를 바꾸지 않는다.
- E 투입 성공으로 삽이 비거나, 시선·거리 이탈, 삽 내려놓기·거치·도구 변경, 회수 시작, 컴퓨터 진입으로 조건을 잃으면 닫힌다.
- 조준한 보일러의 문만 열린다. 다른 보일러의 문은 닫힘 상태를 유지한다.
- 신규 설치·재설치된 보일러와 포장·소지·배치 preview 중인 보일러는 닫힘 자세로 보인다.

### 움직임

- 열기·닫기는 각각 기본 0.2초에 걸쳐 닫힘 자세와 열림 자세 사이를 회전한다.
- 움직이는 도중 조건이 바뀌면 현재 자세에서 곧바로 반대 목표로 방향을 바꾼다. 끝 자세까지 갔다가 돌아오지 않는다.
- 문 움직임은 표현이며 입력 결과를 지연하지 않는다. 열리는 도중이라도 투입 조건이 유효하면 E로 즉시 투입하고, 삽이 비면 그 자세에서 닫히기 시작한다. 완전히 열리기 전에 닫힐 수 있다.
- 닫힌 문 앞을 조준해도 투입구 조준으로 인정한다. 같은 투입구를 계속 조준하는 동안 문 움직임 때문에 조준이 끊겨 열림·닫힘이 반복되거나 떨리지 않는다.
- 문은 표현 전용이다. 열림·닫힘 중 플레이어, 손님, 삽과 떨어진 물건을 밀거나 막지 않는다.
- 쿨러 투입구의 자동 열림은 이번 범위가 아니다.

## 순환기 노동 — 후속 확장 목표

- 허리 높이 상하 레버를 사용하고 조작 중 레버와 계기를 함께 읽을 수 있게 배치한다.
- 빈손으로 유효한 조작부를 바라보고 E 클릭 한 번으로 한 왕복을 시작한다.
- 1초 왕복이 완료될 때 10포인트를 더하며 최대값을 넘지 않는다. 도중의 부분 보상은 없다.
- E를 놓아도 시작한 왕복은 계속된다. 누르고 있다고 다음 왕복이 자동 시작되지 않는다.
- 진행 중 추가 클릭은 무시하고 예약하지 않는다. 다음 왕복은 완료 후 새 클릭을 요구한다.
- 플레이어 이동·시점은 잠그지 않는다. 시선·거리 이탈, 빈손 조건 상실, 컴퓨터 등 외부 조작 모드 진입, 대상 소실과 회수 시작은 미완료 작업을 취소한다.
- 취소 시 진행은 초기화되고 조작 가능한 레버 기본 자세로 돌아간다. 이미 완료한 작업의 잔량은 유지하되 자연 감소는 계속한다.
- 왕복 중에도 설치된 설비의 자연 감소는 계속한다. 이미 가동 중이며 소진·최대 경계가 없는 1초 구간의 순증가는 기본 9포인트다.
- 0에서 시작한 최초 왕복은 완료 전까지 비가동이며, 완료 순간 10을 얻어 가동한다.
- 이 기능은 입력 연타에 따른 속도 증가나 리듬 보너스를 요구하지 않는다.

## 원형 계기 바늘

바늘이 설정한 중심·회전축을 기준으로 움직인다. 숫자 HUD만으로 계기를 대체하지 않는다.

- 보일러의 별도 고정 계기판 메시는 선택 사항이다. 계기판이 본체 외형에 포함돼 있거나 별도 계기판 메시를 비워도 보일러는 정상 설치·투입·가동·회수된다. 이미 지정된 계기판 메시를 강제로 지우지 않는다.
- 움직이는 바늘은 필수다. 바늘이 설정되지 않은 보일러는 현재처럼 Editor 검증에서 오류로 보고되고 정상 설비로 사용되지 않는다.

전체 회전 범위의 정규화 위치를 p, 가동수치를 v, 최대값을 M, 가동 시작 비율을 a라 하면 다음을 따른다.

~~~text
v = 0: p = 0
v > 0: p = a + (1 - a) × v / M
기본 a = 1/3
~~~

- 바늘 0 각도와 최대 각도 사이를 위 p에 대응시킨다. 실제 월드 각도를 임의로 고정하지 않는다.
- 수치 50/100이면 전체 범위의 2/3, 100/100이면 최대 위치다.
- 아주 작은 양수는 1/3 직상단, 정확히 0은 0 위치다. 두 위치 사이의 불연속은 의도된 표시다.
- 투입·왕복 완료 시 증가한 값에 맞추고 자연 감소 중에는 잔량을 따라 내려간다.
- 0이 되면 즉시 0 위치를 표시한다. 별도 지연·임의 흔들림으로 가동 상태를 오해하게 하지 않는다.
- 포장된 설비에는 월드 가동 계기 작동을 요구하지 않지만, 재설치 시 보존 잔량과 일치해야 한다.

## Q32 A — 이번 최소 용량 정책

### 욕탕 설정

- 설정 가능한 상한은 해당 종류 설치용량이다. 모든 설비가 꺼져 있어도 설치용량 안에서 목표·순환도를 미리 설정한다.
- 욕탕 요구량 공식, 빈 욕탕의 예약, 다른 욕탕 설정을 자동 변경하지 않는 규칙은 유지한다.
- 가동수치가 줄어도 설정 slider의 상한은 바뀌지 않는다. 설치·회수로 설치용량이 바뀔 때 기존 방식으로 갱신한다.
- 가동용량 부족은 설정 거절 사유가 아니다. 설치용량 초과 설정은 기존대로 제한한다.

### 실제 효과

- 각 종류의 전체 가동용량이 전체 예약량 이상일 때 해당 효과를 허용한다.
- 미만이면 해당 종류를 요구하는 모든 욕탕에서 해당 효과를 멈춘다. 특정 욕탕 우선 처리, 비례 출력, 부분 용량 분배는 없다.
- 순환 부족은 해당 욕탕의 정화와 능동 수온 조절을 함께 멈춘다.
- 가열 부족은 가열을 요구하는 욕탕의 능동 수온 조절만, 냉각 부족은 냉각을 요구하는 욕탕의 능동 수온 조절만 멈춘다.
- 부족하지 않은 종류의 효과와 자연 실온 복귀·실제 입욕자 오염 증가는 기존 조건에 따라 계속된다.
- 설정값·예약량은 보존한다. 가동용량이 예약량 이상으로 회복되면 컴퓨터 재입력 없이 자동 재개한다.
- 예: 보일러 정격 100 두 대, 가열 예약 150에서 한 대만 가동하면 가열 전체 정지. 두 대가 가동하면 재개한다.
- 예약을 줄여 남은 가동용량 안에 맞춰도 해당 효과가 재개될 수 있다.
- 뜻하지 않은 설비 소실로 설치용량까지 예약량 미만이 되어도 설정을 임의로 줄이지 않는다. 기존 소실·부족 처리와 사용자 감량 가능성을 유지한다.

## 회수·포장·재설치

- 정상 회수는 해당 설비 제거 후 설치용량이 총 예약량 이상일 때 허용한다. 가동 중인 설비도 이 조건을 만족하면 회수할 수 있다.
- 가동용량이 회수 후 부족해지는 것만으로 회수를 막지 않는다. 성공 후 해당 효과를 정지하고 부족을 표시한다.
- 회수 Hold 중 설치용량은 그대로이며 자연 감소와 0 경계 전환은 계속된다.
- 회수 중 해당 설비의 삽 투입·순환기 노동은 허용하지 않는다. 진행하던 미완료 왕복은 취소된다.
- 회수 성공 순간의 가동 잔량과 기존 인스턴스 정격을 회수 아이템이 보존한다.
- 포장·소지·내려놓기·배치 preview 중에는 그 설비의 용량을 제공하지 않고 보존 잔량도 감소하지 않는다.
- 성공적으로 재설치하면 보존된 잔량으로 가동/비가동을 결정하고 설치 상태의 감소를 재개한다.
- 회수 취소·실패 시 설비는 설치 상태에 남고 시간에 따라 감소한 잔량을 과거 값으로 되돌리지 않는다.
- 배치 취소·실패 시 원래 회수 아이템과 보존 잔량은 유지한다.
- 실패 경로에서 설비나 재료가 복제·소실되거나 용량이 중복 합산되면 안 된다.
- 이 보존은 같은 월드의 회수·재설치 계약이며 SaveGame 영속화는 아니다.

## HUD와 컴퓨터

- 조준 HUD는 현재 입력, 작업명, 실행 불가 이유를 표시한다.
- 삽 퍼담기·반환·투입은 삽을 든 E, 순환기 한 왕복은 빈손 E, 설비 회수는 기존 Q Hold로 구분한다. 한 조준 상태에는 실행할 E 행동 하나만 안내한다.
- 삽 작업에는 Hold 안내·진행률을 표시하지 않는다. 순환기의 진행 중 한 왕복과 기존 회수에는 해당 진행을 표시한다.
- 잘못된 재료, 빈 삽, 이미 적재된 삽, 가득 참, 회수 중, 필요한 빈손·도구 조건을 구분해 안내한다.
- 컴퓨터 상단의 각 종류는 예약량, 가동용량, 설치용량을 이름과 함께 표시한다.
- 예: 가열 예약 150 / 가동 100 / 설치 200, 상태는 가동용량 50 부족.
- 정격 설치 자체가 부족한 경우와 설치는 충분하지만 가동이 부족한 경우를 구분한다.
- 막대의 색이나 최대치 처리로 예약량 초과·부족을 숨기지 않는다.
- 기존 1024×576 world screen과 Unreal 기본 UI 요소를 사용하고, 셋의 의미를 구분할 수 있게 읽히게 한다. 세부 배치는 Editor 확인 후 결정한다.
- 지도는 기존 욕탕용 영역과 욕탕만 유지한다. 설비별 잔량·남은 시간 목록은 추가하지 않는다.
- 컴퓨터를 나가거나 다시 들어와도 월드 가동수치·욕탕 설정을 초기화하지 않는다.
- 컴퓨터·배치 모드의 LMB·E 입력이 삽 작업을 함께 발생시키지 않아야 한다.

## 기존 기능 유지 범위

- 욕탕 급수·배수·혼합·수위·슬롯·손님 입욕 조건과 실제 입욕자 오염 증가는 유지한다.
- Q24~Q28의 목표 조절력과 실온 복귀력 경쟁, 파생 임계 순환도, 목표 유지·정체·복귀 상태를 유지한다.
- 기본 온도 임계 10%는 자연 복귀력/최대 목표 조절력에서 파생하는 값이다. 이번 설비 가동수치나 계기 시작 비율 1/3과 관계없다.
- 기본 정화 1%p/s, 손님 오염 0.1%p/s, 목표 조절력 0.5°C/s, 자연 복귀력 0.05°C/s와 기존 authoring 가능성을 유지한다.
- physical carry 한 개 제한, 지정 거치대, free drop, 기존 도구와 물 조작·회수 입력을 유지한다.
- 욕탕 회수 초기화와 설비의 잔량 보존을 혼동하지 않는다.
- 손님 만족도·욕탕 선택을 이번 가동수치나 수온·오염도로 새로 변경하지 않는다.
- 관련 없는 기존 결함을 포괄적으로 수정하는 작업으로 확대하지 않는다.

## Editor authoring 기대와 남은 검증

- 종류별 최대 가동수치·감소속도·재료 한 삽 양, 순환기 왕복 시간·증가량을 조정할 수 있어야 한다.
- 종류별 정격과 필요한 인스턴스 차이는 기존처럼 설정 가능해야 한다.
- 계기 0/최대 각도, 가동 시작 비율, 바늘 회전축·중심, 레버 양끝 자세와 작업 중 가시성을 조정·확인할 수 있어야 한다.
- 보일러 투입구 문의 회전 피벗 위치, 닫힘·열림 회전 자세와 열기·닫기 시간을 조정할 수 있어야 한다. 위치는 보일러 local 기준 cm, 회전은 도, 시간은 초다. 열림 각도는 실제 문 mesh에 맞춰 Editor에서 정하며 이 문서에서 고정하지 않는다.
- 움직이는 문 mesh는 바늘 mesh와 같은 필수 수준이다. 없으면 Editor 검증에서 오류로 보고되고 정상 설비로 사용되지 않는다. 별도 고정 계기판 mesh는 선택이다.
- 현재 저장된 보일러에는 문이 없다. 보일러가 설정 오류 상태로 남지 않도록 수직 검증 전에 문을 준비한다. 임시 표현이어도 열림과 닫힘을 구분할 수 있어야 하며 기존 Cube 투입구만으로 문 동작을 검증했다고 간주하지 않는다.
- 설비 기준 local 공간에서 조작부·계기·투입구 위치를 확인하고, 거리·bounds는 cm, 회전은 도 단위로 기록한다. 현재 미확인 피벗·축 값을 추정해 고정하지 않는다.
- 공급함 재료 구분, 삽의 빈/석탄/드라이아이스 외형, held 자세와 지정 거치 위치를 확인한다.
- 첫 보일러는 실제 투입할 위치와 바늘을 플레이어가 구분할 수 있어야 한다. 최종 고품질 art는 요구하지 않지만 기존 Cube만으로 상호작용과 가동 표시를 검증했다고 간주하지 않는다.
- 현재 Definition 연결 누락은 첫 대상 배치·회수·재설치 검증의 선행 조건이다.
- WBP WidgetTree·추가 용량 표시 공간·실제 입력 연결과 바늘/레버 시각 적합성은 사전조사 미확인 항목이다. Editor 단계에서 실제 확인한다.
- 보고서의 asset 후보 없음, 도구 조회 불가, 아직 실행하지 않음은 서로 구분한다.
- 이 문서는 asset 생성이나 수정이 이미 완료됐다고 주장하지 않는다.

## 첫 보일러 수직 구현

이번 설계는 보일러 한 종류에서 다음 흐름을 완결하는 데 집중한다.

1. 보일러, 석탄 공급함, 공용 삽·지정 거치대, 원형 계기, 욕탕·컴퓨터를 준비한다.
2. 보일러 신규 상태는 비가동이고, 컴퓨터에서 설치용량 기준으로 가열 목표를 예약한다.
3. 빈 삽으로 석탄 공급함을 조준해 E로 즉시 퍼담고 운반한다.
4. 투입구를 조준하면 문이 열리고, E를 누르면 삽이 비고 문이 닫히며 바늘·가동용량이 즉시 올라가고 조건을 만족한 욕탕 가열이 시작된다.
5. 자연 소진으로 바늘이 0이 되면 설치용량·욕탕 설정은 남고 가열만 정지한다.
6. 다시 투입해 컴퓨터 재설정 없이 가열이 재개되는지 확인한다.
7. 잘못된 입력, LMB·F 무반응, 초과분 폐기·가득 참과 문 닫힘, E 반환, 문 열림·닫힘 전환, 내려놓기·거치, 회수 취소·성공·포장·재설치를 함께 확인한다.
8. HUD와 1024×576 화면에서 원인을 판독하고 실제 플레이어 입력으로 검증한다.

보일러의 열 효과 검증에는 순환 공급이 필요하다. 첫 수직 단계에서는 기존 순환 공급 또는 명시적으로 준비한 검증용 공급 상태를 전제조건으로 사용한다. 준비 방식과 테스트에만 적용되는 범위를 후속 설계·검증 문서에 명시하고, 순환기 신규 설치 기본 0이라는 최종 계약의 예외로 배포하지 않는다. 첫 보일러 단계에서 순환기 노동 전체를 구현해야 한다는 뜻은 아니다.

쿨러의 재료 구분·역방향 온도 효과와 수동 순환기의 왕복·취소·진행 UI는 첫 수직 사용자 승인 뒤 확장 단계에서 완결한다. 쿨러도 같은 E 행동 규칙을 따르며, 쿨러 투입구 자동 열림은 이번 범위가 아니다. 아래 후속 시나리오를 첫 보일러 완료로 통과 처리하지 않는다.
