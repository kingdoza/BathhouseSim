# 모델링 스타일 지침서

- 작성일: 2026-10-02 (`MODEL-M1` 결과로 정리)
- 적용 대상: BathhouseSim 설비·소품 스태틱 메시. 모델링 대상과 사용처는 [MODELING_STATIC_MESH_LIST.md](MODELING_STATIC_MESH_LIST.md)에 있다.
- 정본 관계
  - 색과 구역별 재질 종류의 원본은 `ArtSource/Bathhouse/_Pipeline/palettes.json`이고, 재질 표현 방식의 원본은 `bh_lib.py`(`mat_*`, `standard_mats`)다. 이 문서의 색 코드는 읽기용 사본이다. 원본을 바꾸면 이 문서도 함께 고친다.
  - 제작 절차와 import 설정은 `ArtSource/Bathhouse/_Pipeline/README.md`를 따른다.
- 기준 에셋: `Boiler_03`, `Circulator_01`, `Shower_01`, `Vanity_01`, `ClothesLocker_01`. 라인업 렌더는 `.md/Work/MODEL-M1/MODEL-M1_Lineup.png`다.

## 1. 스타일 기준

- 레퍼런스는 Fab "Stylized House Interior"(StylArts, https://fab.com/s/a11a111085b5)이고, 프로젝트 `Content/StylizedKitchen`과 같은 팩이다.
- 한 줄 요약: **오래 써서 낡은 1950년대 레트로 동네 목욕탕을, 손으로 칠한 듯한 스타일라이즈드 PBR로. 색과 재질은 구역마다 다르게(욕탕 민트 도장·타일, 홀 나무, 작업 무도장 철).**
- 사실적인 산업 장비가 아니다. 장난감처럼 읽히는 덩어리, 부드러운 모서리, 확실히 낡았지만 정감 있는 표면을 목표로 한다.
- 레퍼런스에서 참고하는 것은 형태 언어, 비례, 재질 표현 방식(둥근 모서리, 손칠 질감, 모서리 마모)이다.
- **색감은 레퍼런스를 참고하지 않는다.** 팔레트·색 배분·채도는 프로젝트 고유 팔레트(3절)로만 정한다.

## 2. 형태 언어

- **덩어리 우선**
  - 실루엣은 큰 상자·원통 2~4개로 읽혀야 한다. 세부는 큰 면 위에 얹는다.
  - 멀리(5m 이상)서 봐도 기능 부위(문·계기·레버·손잡이)가 구분돼야 한다.
- **둥근 모서리(bevel)**: 날카로운 모서리를 만들지 않는다. 크기별 기준은 다음과 같다.

| 부위 | bevel 폭 | 예 |
|---|---|---|
| 큰 몸체(1m급) | 2.5~4.5cm, 4~5 segment | 보일러·캐비닛 외피 |
| 판·상판·문 | 0.8~1.4cm, 2~3 segment | 상판, 락커 문, 받침 |
| 작은 부품 | 0.2~0.6cm, 2 segment | 손잡이, 판재, 루버 |
| 볼트·리벳·0.5cm 이하 | 없음 | 회전체 단면으로 둥글림 |

- **부품은 약간 과장한다**
  - 계기판·밸브 휠·손잡이·노브는 실물보다 10~30% 크고 두껍게 만든다. 두께는 0.5cm 이상이다.
  - 얇은 선형 디테일은 0.4cm 미만으로 만들지 않는다. 게임 거리에서 사라지기 때문이다.
- **레트로 장식 어휘**(설비마다 2~4개 골라 쓴다)
  - 크롬 띠: 정면을 가로지르는 2cm 막대. 측면은 모서리 앞에서 끊는다.
  - 투톤 판넬: 진한색(`body_dk`) 테두리 문 안에 밝은색(`light`) 판넬을 넣는다.
  - 밝은색 상판·캡: 몸체보다 1~2cm 넓게 내민다.
  - 루버: 도드라진 가로 살 4~5개에 크롬 테를 두른다.
  - 황동 명판·번호판: 테두리를 두르고, 글자는 Georgia Bold로 쓴다.
  - 크롬 베젤 원형 계기판: 크림 다이얼에 빨간 위험 구간을 둔다.
  - 빨간·파란 십자/휠 손잡이, 둥근 표시등, 리벳 줄, 테이퍼 다리와 황동 슈.
- **바닥 처리**
  - 무거운 설비는 주철 받침(plinth)이나 짧은 발 위에 올린다.
  - 가구는 테이퍼 다리를 쓰고, 타일 구조물은 짙은 타일 띠로 바닥을 마감한다.
- **뒷면**: 비워 두지 않는다. 서비스 패널과 볼트 4개 정도의 간단한 디테일을 넣는다. 벽에 붙는 면은 단순해도 된다.

## 3. 구역별 색·재질

설비가 놓이는 공간(정본 `.md/Unreal/BuildingSystem.md` `AllowedFacilityTags`)에 따라 테마를 정한다. 사용자가 2026-10-02에 결정했다.

| 구역 | 테마 | 설비(허용 태그) | 몸체 재질 | 주색 / 진한색 | 밝은색 / 포인트 |
|---|---|---|---|---|---|
| 욕탕 | `bath` | 욕탕, 샤워기, 세신대 | 도장 금속 + 민트 타일 | #84AE9C / #4A7E72 | #E4D5B1 / #C7413B |
| 홀 | `hall` | 옷 락커, 음료 냉장고, 안마의자, 평상, TV, 화장대 | **나무** (진한색도 나무) | #B4693F / #6E4129 | 아이보리 도장 #EFE3CC / 겨자 #D9A23A |
| 작업 | `work` | 보일러, 쿨러, 순환기, 세탁기, 건조기 | **무도장 철** (밝은색은 아연도 강판) | #6E767B / #3E4448 | #A7AEB2 / 빨강 #C8463A |

- **정본**: `ArtSource/Bathhouse/_Pipeline/palettes.json`이다. 위 표는 읽기용 사본이다.
  - `themes`: 테마별 역할 색과 역할별 재질 종류(`paint`·`wood`·`metal`)를 정한다.
  - `assets`: 에셋마다 테마와 개별 덮어쓰기(`override`)를 둔다.
- **개별 색 지정(사용자)**
  - `palettes.json`의 해당 에셋 `override`에 적는다.
    - 색만 바꿀 때: `"body": "#RRGGBB"`
    - 재질까지 바꿀 때: `"body": {"kind": "wood", "color": "#RRGGBB"}`
  - 그 에셋만 `run_all.sh`로 다시 굽는다. 테마 표를 바꾸면 그 테마의 에셋을 모두 다시 굽는다.
- **역할**(build 스크립트는 색이 아니라 역할 이름으로 칠한다)
  - 재질 역할
    - `body`: 몸체 외피
    - `body_dk`: 테두리·문·루버·뒷판
    - `light`: 상판·캡·판넬 안쪽
    - `accent`: 노브·바늘·레버·커플링
    - `hot` / `cold`: 온수·냉수 손잡이
  - 색만 쓰는 역할
    - `tile_a` / `tile_b` / `tile_band` / `tile_grout`
    - `label` / `ink` / `dial_red` / `sign_ink`
    - `shade` / `mirror` / `white`
- **공통 재료색**(테마와 무관, `palettes.json` `base`)
  - 크롬 #C9CDD0, 강철 #9AA2A6, 주철 #3B3F42, 황동 #C49A4A, 구리 #B66A43, 녹 #7A4128
  - 표시등 초록 #7FD08A / 호박색 #F0A040
- **배분 원칙**
  - 주색 60%, 보조(진한색·밝은색) 30%, 포인트(포인트색·크롬·황동·구리) 10%로 나눈다.
  - 냉·온수의 파랑·빨강은 기능 표시이므로 모든 테마에서 유지한다.
- **새 테마**: 새 구역 테마나 시안은 레퍼런스 색감을 쓰지 않고 `themes`에 추가한다. 시안 비교는 `PALETTE="<테마>"`로 강제해 렌더한다.
- **금지**: 순백·순흑, 형광색, 채도가 높은 원색 덩어리.

## 4. 재질 표현

모든 재질은 절차 재질로 칠하고 텍스처로 굽는다(Cycles bake). 규칙은 다음과 같다.

- **도장 금속**(`mat_paint`)
  - 넓은 면에 ±7%의 큰 얼룩을 두고, 손칠 같은 어두운 반점을 더한다.
  - 위는 밝고 아래 20~45cm는 때가 탄 듯 어둡게 한다(`grime`).
  - 볼록한 모서리는 조금 밝게 칠한다(edge highlight). 스타일라이즈드의 핵심이다.
  - 칠 벗겨짐은 **모서리 위주**로 넣고 바탕 금속색을 드러낸다. 넓은 면에는 드물게만 둔다.
  - 기본 `wear`는 몸체 0.35, 밝은색 0.25, 법랑 0.15, 포인트 0.3이다. 노화 강도에 비례해 더해진다(아래).

- **금속**(`mat_metal`)
  - 크롬은 거칠기 0.22, 강철 0.38, 주철 0.55, 황동 0.3이다.
  - 모서리를 밝게 하고, 거칠기는 노이즈로 얼룩지게 한다. 완전한 거울면은 쓰지 않는다.
- **나무**(`mat_wood`, 홀 테마의 `wood` 역할)
  - 결은 세로(Z)로 낸다. 결 대비는 주색의 60% 밝기로 한다.
  - 모서리는 살짝 밝게, 바닥 쪽은 조금 어둡게 한다. 칠 벗겨짐은 넣지 않는다.
  - 노화 시 물얼룩 반점, 가는 긁힘(밝은 생나무), 넓게 닳은 모서리를 더한다.
- **무도장 철**(`mat_iron`, 작업 테마의 `metal` 역할)
  - 큰 산화 얼룩을 둔다.
  - 모서리는 닳아 밝은 강철이 드러나게 한다.
  - 오목한 곳(AO)에 녹(#7A4128)이 끼게 하고, 바닥 쪽은 때를 탄 것처럼 한다.
  - 도장 마모 규칙(`wear`)은 적용하지 않는다.
- **타일**(`mat_tile_box`)
  - 7.5cm 정사각 타일에 크림 줄눈을 쓰고, 타일마다 색을 약간 다르게 한다.
  - 면 방향에 따라 박스 투영해서 늘어나지 않게 한다.
- **거울**(`mat_mirror`): 연청록 그라데이션에 사선 하이라이트 줄무늬를 넣은, 그린 듯한 거울이다.
- **글자·다이얼**(`make_dial`, `make_label`)
  - 렌더해서 만든 이미지를 쓴다. 바탕은 테마의 `label`, 잉크는 `ink`, 글꼴은 Georgia Bold다.
  - 다이얼은 실제 바늘 회전 범위에 맞춰 눈금 호를 그린다.
  - 다이얼 바깥 링은 잉크색으로 하고, 위험 구간은 `dial_red`로 칠한다.
- **노화와 티어(2026-10-02 사용자 결정)**: 저티어 설치물은 낡고, 고티어로 갈수록 낡은 노이즈가 없어져 깨끗해진다.
  - 강도는 `palettes.json` `tiers`(1: 0.7, 2: 0.45, 3: 0.2, 4: 0.0)에서 `assets.<에셋>.tier`로 고른다. `age`(0~1)를 직접 주면 그 값을 쓴다. 현재 5종은 1티어다.
  - 0.35 미만에서는 기본 칠 벗겨짐·얼룩·산화·녹도 함께 줄어든다. 0은 완전히 새것이고, 모서리 하이라이트 같은 스타일 표현만 남는다.
  - 모든 원본 재질에는 마지막으로 노화 층(`age_all_materials`)을 씌운다.
  - 공통: 틈새 때(AO), 위에서 흘러내린 자국, 바닥 45cm 오염 띠, 윗면 먼지, 채도 감소와 약한 누런 기, 때 낀 곳은 거칠고 덜 금속적으로 한다.
  - 흘러내림 색: 철은 녹물, 도장은 녹 섞인 때, 나무는 짙은 물얼룩이다. 황동·구리 틈새에는 녹청을 넣는다.
  - 도장은 칠 벗겨짐이 늘고 벗겨진 가장자리에 녹이 번진다. 철은 녹 면적이 늘어난다. 타일은 줄눈이 때로 어두워진다.
  - 글자·다이얼(이미지 재질)은 노화를 절반만 적용해 읽기 쉽게 둔다.
- **그을음·내부**: 화구 안처럼 들여다보이는 구멍은 거의 검은 그을음 재질(#1E1B19)로 막는다. 빈 구멍을 두지 않는다.

## 5. 기술 규격

- **단위·좌표**
  - build 값은 해당 Blueprint **SceneRoot 로컬 Unreal cm**로 적는다. 변환식은 `Blender = (X, −Y, Z) / 100`이다.
  - 정면이 UE −Y인 설비는 Blender +Y가 정면이고, UE +X인 설비는 Blender +X가 정면이다.
- **pivot**
  - 본체는 바닥 중심 (0,0,0)이다.
  - 움직이는 부품은 BP pivot component 위치가 원점이고, 정지 자세는 BP 자식 mesh 방향을 따른다. 예: 바늘 +X, 문 −X로 뻗음, 레버 +Z.
- **footprint**
  - 본체는 배치 footprint 안에 둔다. 넘어도 되는 경우는 다음 둘뿐이다.
    - 앞면 조작부: 기존 BP 부품 위치까지
    - 벽에 붙는 높은 구조: 샤워 뒷벽처럼 의도한 경우만. README에 적는다.
  - 이어 붙이는 모듈(락커 칸)은 반복 간격 경계를 절대 넘지 않는다.
- **부품 분리**
  - BP가 회전·이동시키는 component만 별도 mesh로 만든다. 나머지 임시 Cube 부품(투입구·계기판 등)은 본체에 합친다.
  - 축을 공유하는 부품은 고정 쪽(보스·경첩 고리)을 본체에, 회전 쪽을 부품 mesh에 나눈다.
- **충돌**
  - `UCX_<메시이름>_NN` convex 2~6개를 쓴다. 본체·큰 돌출부·조작부 단위로 묶는다.
  - 움직이는 부품은 상자 1개 또는 없음으로 한다.
- **재질·텍스처**
  - 에셋당 재질 슬롯 1개(`M_<에셋>`), 텍스처 1세트를 쓴다: BaseColor(sRGB), ORM(R=AO, G=Rough, B=Metal), Normal(DirectX).
  - 해상도는 2048이 기본이고, 큰 타일 면이 있으면 4096을 쓴다.
  - 움직이는 부품도 같은 아틀라스를 쓴다.
- **UV**: UV0은 아틀라스이고, 다이얼·글자 면은 텍셀 밀도 3배로 한다. UV1_Lightmap은 export mesh마다 따로 만든다.
- **삼각형 예산**

| 대상 | 삼각형 | 실적 |
|---|---|---|
| 큰 설비 | 8k~15k | 보일러 10.4k, 순환기 14.0k |
| 가구 | 8k 안팎 | 화장대 8.2k, 샤워기 10.7k |
| 작은 모듈 | 4k 이하 | 락커 3.9k |
| 움직이는 부품 | 1.5k 이하 | — |

- n-gon은 export 때 삼각화한다.
- **이름·폴더**
  - `ArtSource/Bathhouse/<이름>_<번호>/` 아래에 .blend, `SM_<이름>_<번호>[_<부품>].fbx`, `textures/`, `renders/`, `scripts/{build.py, asset_cfg.py}`, README, manifest, validation을 둔다.

## 6. 작업 절차

1. **사전 조사**: `MODELING_STATIC_MESH_LIST.md`와 Editor 읽기 전용 조사로 BP 실측값을 확보한다. 필요한 값은 다음과 같다.
   - component 트리와 상대 위치, footprint, 회전 축·각도
   - 정면 방향, 진열·서는 위치
2. **build.py**: 위 값을 UE cm 그대로 적어 파트를 만든다. `palettes.json` `assets`에 에셋과 구역 테마를 등록하고, 색은 역할 이름(`M["body"]` 등)으로만 칠한다. 색 코드를 직접 쓰지 않는다.
3. **소스 렌더 확인**: Cycles로 소스 렌더(`preview SHOW='source'`)를 뽑아 아래를 확인한다.
   - 정면 방향
   - 부품 위치(BP 값과 대조)
   - footprint 초과 여부
   - 색 배분
4. **베이크 → finalize → export → validate**: `run_all.sh`로 돌린다. 재수입 bounds·UV·재질·UCX 검사를 모두 통과해야 한다.

7. **README 작성**: 메시별 BP component, pivot, 크기와 **Unreal 교체 시 BP 조정 사항**을 적는다. 조정 사항은 scale 1 복원, 자식 상대 위치 0 등이다.
