# PROMPT_ARCHITECTURE — EXPANSION-PURCHASE 공간별 건물과 컴퓨터 확장 구입

- 작업 ID: `EXPANSION-PURCHASE`
- 단계: 기능 명세
- 상태: 완료

상위 작업 `EXPANSION-PURCHASE`의 전체 기능 계약이다. 단위 작업 `EXP-U1`·`EXP-U2`·`EXP-U3`(10절)는 이 문서를 공통 계약으로 쓴다. 단위마다 해당 시나리오만 범위다. 선택 근거는 [QNA_FEATURE_SPEC.md](QNA_FEATURE_SPEC.md)(Q1~Q15, P1~P37)에 있고, Editor 사실은 [REPORT_UNREAL_DISCOVERY.md](REPORT_UNREAL_DISCOVERY.md)와 [REPORT_UNREAL_DISCOVERY_2.md](REPORT_UNREAL_DISCOVERY_2.md)에 있다.

## 1. 목적과 범위

- 가게를 홀·목욕공간·작업공간(지하) 세 공간으로 나누고, 공간마다 경계에 맞는 벽·바닥·천장을 둔다. 기존 설비와 범위 구역은 공간 종류에 맞게 들어간다.
- 플레이어는 컴퓨터의 새 `확장` 탭에서 돈을 내고 공간 하나를 골라 넓힌다. 넓어진 공간에는 벽·바닥·천장과 구역이 그대로 따라붙는다.
- 홀을 넓히면 열쇠 수와 락커 칸 설치 한도가 오른다. 늘어난 칸을 채울 락커(1·4·8칸)를 상점에서 판다.
- 범위 밖은 11절에 있다.

## 2. 현재 동작과 목표 동작

### 2.1 현재 (사전 조사와 Source 근거)

- 확장 단계는 0·1·2 세 단계다. 단계마다 열쇠걸이 열쇠 3·4·8개와 락커 칸 설치 한도 2·4·8칸만 정한다. 시작은 0단계이고, 단계를 올리는 화면·가격·결제는 없다. 원래 배치 시스템 설계(2026-09-06)가 구매·경제·UI를 범위 밖으로 남겼다.
- 단계가 오르면 열쇠걸이의 다음 빈 자리(모두 8자리)에 열쇠가 추가된다. 손님 생성기(5초 간격, 최대 동시 4명)는 확장과 무관하다.
- 1칸 락커 2개가 0단계 한도 2칸을 이미 채운다. 상점은 데이터 규칙으로 락커 판매를 막는다. 새 락커를 얻는 경로가 없다.
- 건물이 없다. 바닥은 높이 0의 평평한 야외 지형이고, 천장과 실내 조명이 없다. 북쪽 임시 큐브 벽 하나만 있다. 지하가 없다. 공간을 나누는 데이터가 없다. 설비는 위치로만 모여 있다(홀 서쪽, 목욕 동쪽, 보일러류 남쪽 띠, 세탁 북동쪽).
- 범위 구역 7개(사용자 표현 "BoundZone")가 있다.
  - 설비 배치 구역 1개가 모든 공간을 덮는다.
  - 쓰레기 생성 구역 1개와 물 얼룩 생성 구역 2개는 공간 경계에 걸쳐 있다.
  - 쓰레기 수거 구역(출입구 밖), 계산대 대기 배회 구역(카운터 옆), 손님 길 범위(전체)가 있다.
- 컴퓨터 화면은 `관리`·`상점` 두 탭(1024×576)이다.
- 프로젝트의 집 mesh(StylizedKitchen `SM_House_*`)는 방 배치가 구워진 한 덩어리라 크기를 바꿔 이어 붙일 수 없다.

### 2.2 목표

- 시작하면 홀·목욕공간(지상)과 작업공간(지하)이 각자 직사각형 경계의 벽·바닥·천장으로 둘러싸여 있다. 실내는 조명으로 밝다. 홀에는 바깥 출입구, 목욕공간으로 가는 통로, 지하로 내려가는 계단이 있다.
- 설비·물건·구역이 공간 종류에 맞게 놓여 있다. 설비는 공간마다 정해진 종류만 놓을 수 있다.
- 컴퓨터 `확장` 탭에서 공간 하나를 골라 넓힐 수 있다. 넓어지는 순간 벽이 물러나고 바닥·천장·조명·배치 구역·손님 길이 넓어진 공간을 덮는다. 쓰레기·물 얼룩 생성 구역 조각도 추가된다.
- 홀을 넓히면 열쇠와 락커 칸 한도가 오르고, 상점에서 산 락커를 넓어진 홀에 설치해 손님을 더 받는다.

## 4. 동작 계약

### 4.1 공간과 건물 (시작 상태)

- 공간은 홀·목욕공간·작업공간 세 종류이고, 종류마다 하나씩 있다. 홀과 목욕공간은 지상, 작업공간은 지하다.
- 각 공간 바닥은 직사각형 하나다. 벽·바닥·천장은 항상 그 경계를 그대로 따른다. 틈, 겹침, 빠져 떨어지는 바닥, 벽 사이 빈틈이 없다.
- 출입·연결
  - 홀 바깥벽 서쪽(지금 출구 자리)에 문짝 없는 출입구 하나가 있다. 손님과 플레이어 모두 지난다. 쓰레기 수거 구역은 출입구 밖 마당에 그대로 있다.
  - 홀↔목욕공간 사이에 문짝 없는 통로가 있다.
  - 홀↔지하 작업공간은 계단으로 오간다. 걸어서 오르내리고, 든 물건(석탄·드라이아이스·삽·수건 바구니·설비 아이템·배송 상자·묶은 봉투 등)을 그대로 들고 다닌다.
- 벽과 천장은 막힌다. 물건을 던지거나 떨어뜨려도 벽·천장 밖으로 나가지 않는다. 통로·출입구·계단으로만 오간다.
- 공간마다 실내 조명이 있어 천장 아래도 어둡지 않다. 바깥 하늘·햇빛·지형은 그대로다.
- 공간 종류마다 벽·바닥·천장 재질이 다르다. 기본 제안: 홀=벽지와 나무 바닥, 목욕공간=욕실 타일, 작업공간=거친 회색 마감. Editor에서 고른다.
- 손님은 지하에 가지 않는다. 손님 길은 홀·목욕공간과 출입구 밖만 덮는다. 손님은 출입구 바깥에서 생겨 출입구로 들어오고, 출입구로 나간다.
- 플레이어 시작 위치는 홀 안 카운터 근처다.
- 건물 밖 장식(옛 욕조 2개와 수면 판, 조리대 4개, 빈 import actor)과 북쪽 임시 큐브 벽은 없앤다. 홀 안 장식 냉장고·청소기 mesh는 홀에 남는다.
- 설비·물건의 공간(0단계, 지금 위치에서 옮김):

  | 공간 | 설비·물건 |
  |---|---|
  | 홀 | 카운터, 컴퓨터, 열쇠걸이, 배송 지점, 음료 수거함, 신발장 2, 옷 락커 2, 렌치 거치대, 걸레·집게 거치대 |
  | 목욕공간 | 샤워기, 욕탕 2, 수건 공급대, 사용 수건함, 때수건 거치대 |
  | 작업공간(지하) | 순환기, 쿨러, 보일러, 석탄·드라이아이스 공급함, 삽 거치대, 세탁기, 건조기, 건조대, 수건 바구니 거치대 |

- 시작 확장 상태는 지금과 같다. 확장 0회, 열쇠 3개, 락커 칸 한도 2칸, 1칸 락커 2개 설치다.

### 4.2 공간별 구역

- 설비 배치 구역: 공간마다 하나이고 그 공간 바닥 전체를 덮는다. 공간별로 놓을 수 있는 설비:

  | 공간 | 놓을 수 있는 설비 |
  |---|---|
  | 홀 | 옷 락커(1·4·8칸), 음료 냉장고, 안마의자, 평상, TV, 화장대 |
  | 목욕공간 | 욕탕, 샤워기, 세신대 |
  | 작업공간 | 보일러, 쿨러, 순환기, 세탁기, 건조기 |

  - 맞지 않는 공간을 조준하면 배치 미리보기가 불가로 표시되고 `이 공간에는 놓을 수 없는 설비입니다`가 보인다.
  - 회수(Q 길게)해 다른 공간으로 옮길 때도 이 표를 따른다.
  - 배치 격자 표시·스냅·회전·확정 등 다른 배치 규칙은 지금과 같다.
- 손님 길: 홀·목욕공간 바닥 전체와 출입구 밖 경로를 덮는다. 지하는 덮지 않는다.
- 쓰레기 생성 구역과 물 얼룩 생성 구역은 처음부터 홀·목욕공간 바닥을 여러 조각으로 나눠 덮는다.
  - 조각 크기는 Editor 조정값이다.
  - 조각마다 지금처럼 동시 최대 개수가 있다. 맵 전체 상한(정리 관리자 값)은 그대로다.
  - 지금처럼 손님이 있는 곳에서 손님 수에 비례해 생기고, 바닥에만 생긴다. 지하에는 조각이 없어 쓰레기·물 얼룩이 생기지 않는다.
- 계산대 대기 배회 구역은 홀의 카운터 옆, 쓰레기 수거 구역은 출입구 밖이다. 둘 다 공간이 넓어져도 크기·위치가 그대로다.
- 컴퓨터 관리 탭의 욕탕 지도는 목욕공간의 배치 구역을 보여 준다.

### 4.3 확장 탭 표시

- 컴퓨터 화면 탭 순서는 `관리 · 상점 · 확장`이다. 처음 들어오면 기본 탭은 `관리`다.
- 확장 탭이 보여 주는 것
  - 현재 확장 횟수(`현재 확장 단계: 0`)와 잔액
  - 설치된 락커 칸 수/한도(`설치된 락커 칸 2/2`)
  - `홀`·`목욕공간`·`작업공간` 세 선택지. 선택지마다 넓어지기 전후 크기(`홀 21m×14m → 25m×14m`)를 보여 준다. `홀` 선택지는 늘어나는 열쇠·락커 한도(`열쇠 3개 → 4개`, `락커 칸 한도 2칸 → 4칸`)도 함께 보여 준다.
  - 이번 구입 가격
- 하나를 고르면 그 선택지가 강조되고 `확장 구입 (가격)` 버튼이 켜진다. 고르기 전에는 버튼이 꺼져 있다.
- 공간별 넓힘 횟수 상한에 닿은 선택지는 고를 수 없고 `이 공간은 더 넓힐 수 없습니다`가 보인다.
- 전체 구입 횟수 상한에 닿으면 선택지와 구입 버튼 대신 `최대 확장 단계입니다`가 보인다.
- 잔액이 가격보다 적으면 구입 버튼이 꺼지고 `N원 부족`이 보인다. 손님 결제 등으로 잔액이 바뀌면 화면을 다시 열지 않아도 즉시 다시 판단한다.
- 확장을 쓸 수 없는 상태(확장 관리 데이터가 없거나 잘못됨)면 `확장을 사용할 수 없습니다`가 보이고 구입할 수 없다.
- 화면 문구는 횟수 번호를 쓰고, 단계별 이름은 따로 두지 않는다. 금액은 상점과 같이 천 단위 구분 + `원`이다.

### 4.4 구입 입력, 즉시 피드백, 완료 시점

1. 선택지를 클릭해 공간을 고른다(다시 다른 선택지를 누르면 바뀐다).
2. `확장 구입 (가격)`을 누르면 같은 자리에 `정말 구입할까요?`와 `확인`·`취소`가 나온다. 돈·공간은 아직 그대로다.
3. **`확인`을 누르는 순간이 완료 시점이다.** 같은 순간 다음이 모두 일어난다.
   - 돈이 정확히 한 번 빠진다. 기존 돈 HUD에 변화량(`−100,000`)이 2초 보인다.
   - 고른 공간이 넓어진다. 바깥벽이 물러나고, 바닥·천장·조명이 새 경계를 덮는다.
   - 그 공간의 배치 구역과 손님 길(홀·목욕공간)이 넓어진 바닥을 덮는다. 홀·목욕공간이면 늘어난 바닥에 쓰레기·물 얼룩 생성 조각이 추가된다.
   - 홀을 골랐으면 열쇠걸이의 다음 빈 자리에 새 열쇠와 고리가 나타나고(번호는 이어서), 락커 칸 설치 한도가 오른다. 다른 공간을 골랐으면 열쇠·한도는 그대로다.
   - 확장 탭에 `확장 완료`가 보이고, 모든 표시가 새 상태 기준으로 바뀐다. 선택은 해제된다.
- 공사 시간이나 화면 밖 알림은 없다.
- 버튼을 빠르게 여러 번 눌러도 한 번만 구입·결제된다. 구입 직후 다음 구입은 새 상태로 다시 판단한다. 돈이 남아 있으면 바로 다음 확장을 살 수 있다.

### 4.5 성공 후 상태

- 넓어진 바닥은 바로 걸을 수 있다. 손님도 다니고(홀·목욕공간), 공간별 표에 맞는 설비를 놓을 수 있다. 쓰레기·물 얼룩도 생긴다(홀·목욕공간).
- 넓어지는 순간 사라지는 것은 옛 바깥벽뿐이다. 새 벽은 원래 건물 밖이던 자리에만 생긴다.
  - 그래서 플레이어·손님·설비·떨어진 물건이 밀리거나 벽에 갇히지 않는다.
  - 공간 사이 벽은 움직이지 않는다. 공간은 다른 공간과 겹치지 않는 방향으로만 넓어진다.
- 이미 설치된 설비, 진행 중인 손님 행동, 욕탕 물, 열쇠 번호·위치(기존·손님 소지·반납 대기)는 바뀌지 않는다.
- 한도가 오르면 한도 때문에 막혀 있던 락커 아이템도 다시 조준하면 설치할 수 있다.
- 확장은 되돌릴 수 없고 환불도 없다. 저장 기능이 없으므로 게임을 다시 시작하면 확장 0회 상태로 돌아간다(돈·설비와 같다).

### 4.6 락커 상품

- 상점 상품 목록 맨 뒤에 `1칸 락커`, `4칸 락커`, `8칸 락커`가 이 순서로 붙는다.
- 담기·수량·장바구니 상한·주문·배송·개봉·운반·배치·회수·재배치는 다른 설비 상품과 같다. 락커는 홀에만 놓을 수 있다(4.2).
- 설치 한도보다 많이 살 수 있다. 설치하려 하면 지금처럼 `현재 확장 단계의 설치 가능한 락커 칸 수를 초과합니다`로 막히고, 홀을 넓혀 한도가 오르면 설치할 수 있다.
- 락커 아이템은 버릴 수 없다. 쓰레기 수거 구역에 두어도 사라지지 않는다.
- 손님 생성 간격과 최대 동시 손님 수는 확장과 무관하다. 실제로 받는 손님 수는 지금처럼 설치된 락커 칸 수가 정한다.

### 4.8 반드시 유지할 기존 기능

- 컴퓨터 진입·이탈과 이탈 위치, 관리·상점 탭의 모든 동작, 기본 탭 `관리`, 이탈 뒤 마지막 화면 상태 유지(확인 대기는 4.9대로 취소), 화면 휠 스크롤 규칙(`COMPUTER-WHEEL-SCROLL`). 확장 탭에 스크롤 영역이 생기면 같은 휠 규칙을 따른다.
- 손님 루틴 전체(체크인 열쇠, 락커 칸 lease, 탈의·착의, 샤워, 입욕, 수건, 계산, 퇴장, 줄 넘침 배회, 쓰러짐 회복). 출입구 위치가 바뀌어도 같은 흐름이다.
- 설비 노동(삽 석탄·드라이아이스 투입, 순환기 레버, 계기)과 욕탕 수온·순환 효과. 위치만 지하로 옮긴다.
- 수건 순환(공급대 → 손님 → 사용 수건함 → 바구니 → 세탁 → 건조 → 공급대). 사용 수건함(목욕공간)과 세탁기(지하) 사이를 바구니를 들고 계단으로 나른다.
- 상점 주문·배송(배송 지점은 홀)·개봉·쓰레기 수거, 청소(걸레·집게·봉투), 서비스 설비, 열쇠 번호 불변, 물리 운반 규칙.

### 4.9 실패·취소·복구

- `취소`를 누르거나, 확인 대기 중 다른 탭으로 가거나, 컴퓨터를 나가면 확인이 취소된다. 돈·공간·열쇠·한도는 그대로이고, 다시 오면 선택·구입 버튼부터 시작한다.
- 확인 대기 중 잔액이 가격보다 적어지면 `확인`이 꺼지고 부족액이 보인다.
- 구입이 어떤 이유로든 완료되지 못하면 돈·공간·열쇠·한도·구역이 모두 구입 전과 같다. 일부만 바뀐 상태가 보이지 않는다.
- 막힌 설치(공간 종류 불일치·한도 초과)는 아이템과 미리보기를 손에 그대로 두고, 위의 이유 문구만 보인다.

### 4.10 하지 않는 동작

11절 비목표를 따른다.

## 5. 시나리오 (Given/When/Then)

단위 표시: [U1] 공간 건물, [U2] 확장 구입 수직, [U3] 전체 확장. 모두 사용자 PIE에서 확인한다.

### 공간 건물 [U1]

- **EXP-001** Given 새 게임 시작, When 플레이어가 홀·목욕공간·지하를 둘러본다, Then 각 공간이 직사각형 벽·바닥·천장으로 둘러싸여 있다. 벽 사이 틈, 바닥 구멍, 겹쳐 깜빡이는 면이 없고 천장 아래도 밝다.
- **EXP-002** Given 홀, When 서쪽 출입구로 나갔다 들어온다, Then 문짝 없이 지나간다. 밖 마당에 쓰레기 수거 구역이 있고, 묶은 봉투를 두면 지금처럼 수거된다.
- **EXP-003** Given 홀, When 목욕공간 통로를 지난다, Then 막힘 없이 오간다.
- **EXP-004** Given 석탄(또는 수건 바구니, 설비 아이템)을 든 플레이어, When 홀 계단으로 지하에 내려갔다 올라온다, Then 계속 들고 있고 떨어뜨리거나 끼이지 않는다.
- **EXP-005** Given 아무 공간, When 물건을 벽·천장 쪽으로 던지거나 떨어뜨린다, Then 벽·천장을 뚫고 나가지 않는다.
- **EXP-006** Given 새 게임, When 공간별 설비를 확인한다, Then 4.1의 표대로 놓여 있고 건물 밖 장식과 북쪽 임시 벽이 없다. 플레이어는 홀 카운터 근처에서 시작한다.
- **EXP-007** Given 손님 생성, When 손님이 루틴을 진행한다, Then 출입구 밖에서 들어와 체크인 → 락커 → 샤워·입욕 → 계산 → 출입구로 나간다. 지하에는 가지 않고, 벽에 끼이거나 길을 잃지 않는다.
- **EXP-008** Given 욕탕 설비 아이템, When 홀·지하 바닥을 조준한다, Then 미리보기가 불가이고 `이 공간에는 놓을 수 없는 설비입니다`가 보인다. When 목욕공간을 조준한다, Then 지금처럼 놓을 수 있다. 보일러는 지하에만, 락커·음료 냉장고는 홀에만 놓인다(4.2 표 전체).
- **EXP-009** Given 지하에 놓인 세탁기, When 회수(Q 길게)해 홀에 놓으려 한다, Then 불가 문구가 보이고, 지하에는 다시 놓을 수 있다.
- **EXP-010** Given 홀·목욕공간에 손님이 있다, When 시간이 지난다, Then 쓰레기·물 얼룩이 손님이 있는 공간 바닥에 생긴다. 지하에는 생기지 않는다.
- **EXP-011** Given 지하 보일러·쿨러·순환기, When 삽으로 석탄·드라이아이스를 넣고 순환기 레버를 돌린다, Then 지금처럼 작동하고 욕탕 수온·순환이 반응한다.
- **EXP-012** Given 목욕공간 사용 수건함에 사용 수건, When 바구니에 담아 계단으로 지하 세탁기·건조기를 거쳐 공급대에 채운다, Then 수건 순환이 지금처럼 끝난다.
- **EXP-013** Given 컴퓨터 관리 탭, When 욕탕 지도를 본다, Then 목욕공간 배치 구역 기준으로 욕탕이 표시되고 설정 변경이 지금처럼 동작한다.
- **EXP-014** Given 계산대 줄이 넘친다, When 손님이 더 온다, Then 카운터 옆 대기 배회 구역에서 지금처럼 서성인다.
- **EXP-015** Given 컴퓨터, 상점, 배송 지점(홀), When 주문·배송·개봉한다, Then 지금처럼 동작한다(U1에는 확장 탭이 없다).

### 확장 구입 수직 [U2] — 홀 1회

- **EXP-020** Given 컴퓨터 진입, When 탭을 본다, Then `관리 · 상점 · 확장` 순서이고 기본 탭은 `관리`다.
- **EXP-021** Given 확장 0회·잔액 충분, When 확장 탭을 연다, Then 다음이 보이고 구입 버튼은 꺼져 있다.
  - `현재 확장 단계: 0`, `설치된 락커 칸 2/2`, 가격, 잔액
  - 세 선택지와 각각 넓어지기 전후 크기
  - `홀` 선택지의 `열쇠 3개 → 4개`, `락커 칸 한도 2칸 → 4칸`
- **EXP-022** Given 잔액 < 가격, When `홀`을 고른다, Then 구입 버튼이 꺼져 있고 `N원 부족`이 보인다. When 손님 결제로 잔액이 가격 이상이 된다, Then 화면을 다시 열지 않아도 버튼이 켜진다.
- **EXP-023** Given `홀` 선택·잔액 충분, When `확장 구입` → `확인`, Then 그 순간 다음이 모두 일어난다.
  - 돈이 한 번 빠지고 HUD에 변화량이 보인다.
  - 홀 바깥벽이 물러나고 바닥·천장·조명이 넓어진 홀을 덮는다.
  - 열쇠걸이에 4번 열쇠가 나타난다.
  - 탭이 `확장 완료`, `현재 확장 단계: 1`, `설치된 락커 칸 2/4`로 바뀐다.
- **EXP-024** Given EXP-023 직후, When 넓어진 홀 바닥을 걷고 설비 미리보기를 대 본다, Then 걸을 수 있고 홀 설비를 놓을 수 있다. 손님도 그 바닥을 지나다니고 쓰레기가 생길 수 있다.
- **EXP-025** Given 옛 홀 바깥벽 바로 안쪽에 플레이어·손님·떨어진 물건이 있다, When 홀을 넓힌다, Then 아무것도 밀리거나 끼이거나 사라지지 않는다.
- **EXP-026** Given `확인` 대기, When `취소`(또는 다른 탭, 또는 컴퓨터 이탈), Then 돈·공간·열쇠·한도가 그대로이고 다시 오면 구입 버튼부터 시작한다.
- **EXP-027** Given `확인` 대기, When `확인`을 빠르게 여러 번 누른다, Then 한 번만 결제되고 한 번만 넓어진다.
- **EXP-028** Given 확장 1회(한도 4칸, 설치 2칸), When 상점에서 `1칸 락커`를 사서 배송·개봉하고 넓어진 홀에 놓는다, Then 설치되고 `설치된 락커 칸 3/4`가 된다. 손님이 3명 이상 동시에 락커를 쓴다.
- **EXP-029** Given 확장 0회(한도 2/2), When `1칸 락커`를 사서 홀에 놓으려 한다, Then 구매는 되지만 설치는 `현재 확장 단계의 설치 가능한 락커 칸 수를 초과합니다`로 막히고 아이템은 손에 남는다. When 홀을 한 번 넓힌 뒤 다시 조준한다, Then 설치된다.
- **EXP-030** Given 락커 아이템, When 목욕공간·지하에 놓으려 한다, Then 공간 불가 문구로 막힌다. When 쓰레기 수거 구역에 둔다, Then 사라지지 않는다.
- **EXP-031** Given 확장 관리 데이터가 없는 레벨(Editor로 확인용 구성), When 확장 탭을 연다, Then `확장을 사용할 수 없습니다`가 보이고 돈은 바뀌지 않는다.
- **EXP-032** Given 확장 탭과 상점 탭, When 관리·상점 탭을 쓰고 목록을 휠로 스크롤한다, Then 지금과 같다.

### 전체 확장 [U3]

- **EXP-040** Given 확장 0회, When `목욕공간`을 골라 산다, Then 목욕공간이 넓어지고 열쇠·락커 한도는 그대로다. 넓어진 바닥에 욕탕을 놓을 수 있고 물 얼룩 생성 조각이 추가된다.
- **EXP-041** Given 확장 0회, When `작업공간`을 골라 산다, Then 지하가 넓어지고 넓어진 바닥에 보일러를 놓을 수 있다. 쓰레기·물 얼룩은 생기지 않는다.
- **EXP-042** Given 홀 1회 확장, When 다시 `홀`을 골라 산다, Then 홀이 한 번 더 넓어지고 열쇠 5~8번이 나타나며 한도가 8칸이 된다. 가격은 2번째 구입 가격이다.
- **EXP-043** Given 전체 구입 횟수 상한에 닿음, When 확장 탭을 본다, Then `최대 확장 단계입니다`가 보이고 살 수 없다.
- **EXP-044** Given 공간별 상한을 1로 조정한 설정에서 홀을 1회 넓힘, When 확장 탭을 본다, Then `홀` 선택지는 고를 수 없고 `이 공간은 더 넓힐 수 없습니다`가 보인다. 다른 공간은 고를 수 있다.
- **EXP-045** Given 전체 상한을 3으로 조정하고 가격·홀 효과 표를 3회까지 채운 설정, When 세 번 산다, Then 세 번 모두 적용된다. 표가 상한보다 짧으면 Editor에서 잘못된 데이터로 알린다.
- **EXP-046** Given 홀 확장으로 한도 여유, When `4칸 락커`·`8칸 락커`를 사서 배송·개봉·운반·설치한다, Then 다른 설비처럼 동작하고 설치 칸 수가 그만큼 오른다.

## 6. Editor 사전 조사 요약

- 확장 정의 1개, 단계 3개(열쇠 3/4/8, 락커 칸 한도 2/4/8), 시작 0단계, 열쇠걸이 자리 8개(1~8번).

- 손님 생성기 1개(5초, 최대 4명, 지금 위치 락커 남쪽). 확장 단계를 쓰는 Content는 없다.
- 건물 없음(지형 바닥 Z=0, 천장 없음, 북쪽 임시 큐브 벽), 지하 없음, 실내 조명 없음, Data Layer 없음.
- 범위 구역 7개, 배치 구역 1개가 전체를 덮는다. 설비 위치 군집과 평면도는 2차 보고서 3·8절에 있다.

## 7. Editor authoring 기대

- 공간 세 개의 0회 크기·위치, 공간별·횟수별 넓힘 양·방향, 천장 높이, 지하 깊이, 통로·출입구·계단 위치, 재질, 조명, 생성 조각 크기를 Editor에서 정하고 바꿀 수 있다. 값을 바꾸면 벽·바닥·천장·구역이 다시 손으로 맞추지 않아도 경계를 따른다.
- 가격, 전체·공간별 상한, 홀 넓힘 효과 표, 락커 상품 가격을 Editor에서 바꿀 수 있다.
- 잘못된 설정(공간 겹침, 열쇠걸이 자리 초과, 표 길이 부족)은 Editor에서 알린다.
- 기존 설비 재배치와 장식·임시 벽 제거, 손님 생성 위치 이동은 Level authoring이다(4.1).
- 확장 탭 화면은 기존 컴퓨터 화면 스타일·크기(1024×576)에 맞춘다.

## 8. 실패·취소·복구 계약

## 10. 단위 구성 (Q13 A, 수직 구현)

C++와 Content가 함께 바뀐다. 새 UI 입력, Actor·collision·Navigation 변화와 여러 설비 공통 적용도 있다. 그래서 단위로 나누고, 단위마다 사용자 PIE 승인 뒤 다음 단위의 아키텍처를 시작한다. 단위 작업 폴더는 `.md/Work/EXPANSION-PURCHASE/<단위 ID>/`다.

| 단위 | 범위 | 시나리오 | 대표 시나리오 |
|---|---|---|---|
| `EXP-U1` 공간 건물 | 0회 크기의 세 공간 벽·바닥·천장·조명·출입구·통로·계단, 설비 재배치, 공간별 배치 구역·설비 종류 제한, 손님 길, 생성 조각, 장식 제거, 손님 생성 위치. 확장 구입 없음. 단, 공간 크기가 Editor 값대로 바뀌면 건물·구역이 따라가야 한다(4.7) | EXP-001~015 | EXP-007(손님 한 명이 출입구로 들어와 전 루틴을 마치고 나감)과 EXP-004 |
