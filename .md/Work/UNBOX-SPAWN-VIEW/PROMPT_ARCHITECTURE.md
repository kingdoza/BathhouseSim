# PROMPT_ARCHITECTURE — UNBOX-SPAWN-VIEW 플레이어 앞 생성 위치를 카메라 정면 기준으로

- 작업 ID: `UNBOX-SPAWN-VIEW`
- 단계: 기능 명세
- 상태: 완료

사용자 답변(`QNA_FEATURE_SPEC.md`, 2026-10-01)과 Editor 사전 조사(`REPORT_UNREAL_DISCOVERY.md`)를 반영한 사용자 최종 승인용 계약이다. 최종 승인 전에는 아키텍처 입력이 아니다. 최종 승인 때 사전 조사로 새로 둔 전제 P9·P10과 P2 정정(4절)도 함께 확인받는다.

## 1. 목적과 범위

사용자 요청 원문: "언박싱등의 플레이어앞에 물체가 생길때 너무 아래에서 생기는데 생성위치가 플레이어 카메라 정면 기준이 맞는지 확인."

플레이어 행동과 관찰 결과로 다시 쓰면 다음과 같다.

- 플레이어가 무언가를 해서 자기 앞에 새 물체가 생길 때, 그 물체는 플레이어가 보고 있는 화면 정면(카메라 시선 방향)에 나타나야 한다.
- 지금은 앞을 똑바로 보고 상자를 열어도 물품이 발밑 가까운 낮은 곳에 생겨 화면 아래로 벗어나 보이지 않는다.

이번 작업은 "플레이어 앞에 새 물체를 만드는 경로" 두 개(배송 상자 개봉, 집게 봉투 묶기)의 생성 위치 기준만 바꾼다. 무엇이 생기는지, 몇 개가 생기는지, 생긴 뒤의 물리·상호작용 규칙은 바꾸지 않는다.

## 5. 동작 계약

### 5.1 시작 조건과 입력

- 개봉: 배송 상자를 들고 LMB(기존과 같음). 컴퓨터·배치 모드가 LMB를 먼저 가져가는 우선순위 유지.
- 봉투: 집게를 들고 봉투에 쓰레기가 1개 이상일 때 RMB(기존과 같음). 조준 대상과 무관.
- 입력 순간의 카메라 위치·시선 방향이 생성 기준이다. 시선은 위·아래 각도(pitch, 제한 ±80°)를 포함한다(Q2 A).

### 5.2 생성 위치 (1단계: 시선 앞)

- 무리(봉투는 봉투 하나) 전체가 카메라에서 시선 방향으로 생성 거리 이상 앞에 있다. 카메라에서 시선 방향으로 잰 무리의 가장 가까운 부분까지 거리가 생성 거리다(Q3 B). 무리가 커지면 무리 중심은 그만큼 더 멀어진다.
- 그래서 1단계로 생긴 무리는 카메라를 감싸거나 카메라에 닿지 않고, 생성 순간 화면 정면에 보인다.
- 무리는 시선 방향에 대해 좌우·위아래 가운데 정렬로 보인다.
- 물품은 위·아래를 보고 열어도 선 자세이고, 좌우 방향(yaw)만 무작위다(Q27 A 유지, P3). 봉투는 지금처럼 플레이어가 보는 좌우 방향으로 선다.
- 수평으로 보면 생성 순간 무리 또는 봉투가 화면 중앙 부근, 눈높이(바닥 위 약 166cm)에 보인다.
- 아래를 보면 앞쪽 아래, 바닥보다 위에 생긴다. 바닥에 닿거나 파고든 채 생기지 않는다.
- 거의 발밑을 보면(생성 거리 기본값에서 개봉 약 −72.5°, 봉투 약 −60°보다 아래) 생성 위치가 플레이어 몸이 서 있는 자리와 겹칠 수 있다. 그 자리를 그대로 쓰고 다른 단계로 넘기지 않는다(P9). 생긴 물체는 플레이어를 밀지 않고, 플레이어도 그 물체에 막히지 않아 걸어 나갈 수 있다(P5). 몸과 겹치는 자리를 금지하면 앞쪽 바닥(2단계)으로 넘어가 화면 위쪽 밖에 생기기 때문이다.
- 위를 보면 앞쪽 위 공중에 생기고 떨어진다. 천장에 닿거나 천장 위에 생기지 않는다.

### 5.3 막혔을 때 (Q5 B)

순서대로 시도하고 처음 성공한 곳에 생긴다. 1·2·3단계 모두 기존 금지 조건을 지킨다(P2).

- 벽·바닥·천장·기존 물체 안에 생기지 않는다.
- 개봉은 손님 몸 안에도 생기지 않는다(SHOP-041 유지). 봉투는 현재처럼 손님을 막는 대상으로 보지 않는다(P2 정정).
- 벽·천장 너머에 생기지 않는다.
- 개봉 물품은 생성 직후 겹침이 풀리며 밀려나도 벽·천장에 박혀 시작하지 않을 여유를 둔다.
- 바닥 쓰레기·물 얼룩은 봉투 생성을 막지 않는다(기존 유지).

단계:

1. 시선 방향 당김: 생성 거리를 카메라 쪽으로 줄여 가며(하한까지) 5.2 규칙의 빈 공간을 찾는다. 하한까지 줄여도 무리가 카메라에 닿지 않는다.
2. 바닥 정면: 현재 계약의 정면 규칙(발바닥 기준 수평 전방, 개봉 밑면 바닥 + 20cm·봉투 바닥 바로 위, 수평 당김)을 쓴다. 위를 보거나 천장이 낮거나 시선 앞이 벽이라 1이 실패해도 앞쪽 바닥 위에 생기게 한다.
   - 이 단계로 생긴 무리도 카메라를 감싸거나 카메라에 닿지 않는다(P10). 설비가 많은 큰 무리는 현재 규칙대로면 카메라를 감쌀 수 있으므로, 감싸지 않는 범위에서 앞쪽 바닥에 생기고 그런 자리가 없으면 다음 단계로 간다.
   - 1개짜리 등 작은 무리와 봉투의 바닥 정면 위치는 현재와 같다.
3. (개봉만) 머리 위 쌓기: 현재 계약 그대로(플레이어 머리 위, 카메라보다 위).
4. (개봉만) 최후 수직 쌓기: 현재 계약 그대로. 개봉은 항상 성공한다. 정상 공간에서는 도달하지 않으며, 이 단계만 카메라를 감쌀 수 있다.

- 봉투는 1·2가 모두 실패하면 `봉투를 놓을 공간이 없음`을 표시하고 봉투 개수·집게·월드가 그대로다(P4, 현재 실패 계약 유지).

### 5.4 생긴 뒤의 물리 (Q4 A)

- 생긴 위치에서 추가 속도 없이 중력으로 떨어진다. 공중에 생기면 그 높이에서 떨어진다(P7).
- 개봉 물품은 지금처럼 같은 상자 물품끼리만 일부 겹쳐 생기고 엔진 충돌 해소로 서로 밀어내며 튄다(Q29 B, Q30 B 유지). 겹침 깊이 조정값과 튐 세기 관계(SHOP-043)는 그대로다.
- 높은 곳에서 떨어져도 바닥 아래·벽 너머·맵 밖으로 빠지지 않는다. 빠지면 기존 맵 밖 복구가 동작한다.
- 생긴 물체는 플레이어와 손님을 밀지 않는다(기존 Pawn 무시 유지, P5). 발 근처나 플레이어 몸 자리에 생기거나 떨어져도 플레이어가 밀리거나 갇히지 않는다.

### 5.5 즉시 피드백과 완료 시점

- 개봉: LMB를 누른 순간 상자가 사라지고 빈손이 되며 같은 순간 물품이 생긴다(기존과 같음). 진행 표시 없음.
- 봉투: RMB를 누른 순간 봉투가 생기고 집게 봉투 개수가 0이 된다(기존과 같음). 실패하면 HUD 실패 문구만 바뀐다.
- 새 HUD 문구·표시·연출은 없다(P7).

### 5.6 실패·취소·복원

- 개봉은 실패하지 않는다(항상 성공 유지). 내부 생성 실패로 개봉이 취소되면 지금처럼 상자는 손에 남고 생긴 물품은 하나도 남지 않는다.
- 봉투 실패 시 집게 봉투 개수, 월드, 손에 든 집게가 그대로다.

## 12. 설계에 맡김

- 시선 방향 위 무리 정렬 기준과 "가장 가까운 부분" 판정 방법.
- 바닥 정면 단계에서 큰 무리가 카메라를 감싸지 않게 하는 방법(P10의 관찰 결과만 계약).
- 시선 당김·바닥 정면·머리 위 단계의 시도 횟수와 계산 비용 배분.
- 기존 조정값 재사용 또는 새 조정값 추가, 두 경로의 계산 공유 여부.
- 시야 검사 기준점(현재 capsule 중심)을 카메라로 바꿀지 등 벽 너머 금지 판정 방법.
