- **이 문서는 설계 에이전트에 직접 넘기지 않는다.** 서비스 시설 전체의 기능 계약을 한곳에 모아 둔 참조 정본이다. 구현은 수직 단위로 진행하며, 단위가 시작될 때 그 단위의 계약만 뽑아 메인 `.md/PROMPT_ARCHITECTURE.md`에 옮겨 설계 입력으로 쓴다(Q32).
- 구현 단위 명세를 쓰거나 구현 중 결정이 바뀌면 이 문서에도 되돌려 반영한다.

- 전제: 조작 통일 작업(메인 `.md/PROMPT_ARCHITECTURE.md`, CTRL-001~029)이 완료된 상태를 기준으로 쓴다(사용자 지시 2026-09-28).

이 문서는 플레이어 입력, 월드·화면 결과, 손님 이용 시 시설 쪽 변화, 실패 경로, Editor 조정값과 수용 기준만 정한다. 클래스, 데이터 구조, 실행 방식, 손님 행동 구현 방식과 파일 구성은 각 구현 단위의 설계 단계가 결정한다.

## 목적과 범위

목욕탕 운영에 서비스 시설을 더한다. 플레이어는 물품을 사서 진열·보충하고, 쓰레기를 치우고, 수금·수리·세신 같은 노동을 한다.

| 구분 | 포함 |
|---|---|
| 진열 서비스 | 품목 박스 공통 규칙, 진열 공통 규칙(넣기·꺼내기·넣기 프리뷰·꺼내기 표시), 음료 냉장고, 공용 화장대, 샤워 비품 |
| 기존 진열·보관 시스템 | 수건 선반·세탁기·건조기 넣기 프리뷰, 사용 수건통 꺼내기 표시 |
| 청소 | 쓰레기 생성과 집게+봉투 줍기, 묶은 쓰레기봉투, 물 얼룩 생성 규칙 변경 |
| 처분 | 쓰레기 수거 구역, 기존 쓰레기통 레벨 제거 |
| 배치형 서비스 설비 | 안마의자(수금·고장·수리), 세신대·때수건(세신 미니게임), 평상, TV |
| 손님 최소 이용 계약 | 시설별 점유, 이용 시간, 이용 중·후 시설 변화(소모·돈·고장), 이용 불가 조건(Q40 A) |
| 상점 | 새 설비와 품목 박스 판매 |

범위 밖:

- 손님이 언제·왜·어떤 확률로 어느 시설에 가는지, 이동 경로와 우선순위(손님 루틴 기획)
- 만족도 영향(쓰레기, TV, 비품 부족 등)
- 날짜 시스템(수거는 임시 주기로 대신)
- 유통기한, 온도, 전력, 저장·불러오기, 멀티플레이

## 현재와 목표

근거는 현재 정본 문서(`Architecture/*`, `Unreal/*`)다. 이 전체 명세를 위해 Editor·PIE를 새로 조사하지 않았다. 구현 단위별 사전 조사 필요 여부는 "구현 단위 계획"에 적는다.

| 대상 | 현재 | 목표 |
|---|---|---|
| 상점 판매 | 설비 7종(욕탕, 샤워기, 세탁기, 건조기, 보일러, 쿨러, 순환기) | + 새 설비 6종, 품목 박스 7종 |
| 배송 상자 내용물 | 설비 아이템만 | + 품목 박스 |
| 진열 시스템 | 수건 선반(깨끗한 수건, 쌓기 표현)만 | + 냉장고·화장대·샤워 비품. 모든 진열에 넣기 프리뷰 |
| 샤워기 | 손님 샤워 자리 2개, 회수 조건 없음(정본에 기재 없음) | + 샴푸·바디워시 비품 자리, 손님 사용 중 회수 불가, 회수 시 비품 보존 |
| 물 얼룩 생성 | 전체 간격마다 가중치로 고른 구역에 무작위 생성, 손님 수와 무관 | 구역 안 손님 수에 비례, 손님 없는 구역은 생성 없음, 바닥에만 |
| 쓰레기 | 없음 | 인원 기반 생성, 집게+봉투로 줍기 |
| 버리기 | 쓰레기통 조준 E(판매 설비 아이템·배송 상자) | 쓰레기통은 레벨에서 제거(코드는 남김). 수거 구역에 두면 수거 시점에 사라짐 |
| 몽키스패너 | 대상과 무관한 LMB 휘두르기 | + 고장 난 안마의자 조준 시 LMB 누르고 있기로 수리 |
| 세탁기·건조기 | 넣을 때 표시 없음. 수건은 넣는 순간 기계 안 무작위 위치에 놓이고 마지막에 넣은 것부터 빠짐. 넣기는 대기, 빼기는 완료 상태에서만 | 진열대와 같은 규칙: 기계 안 다음 자리에 넣기 프리뷰, 다음에 빠질 수건 강조, 조준 시 뚜껑·문 자동 열림. 대기 상태에서도 빼기 허용 |
| 수건 선반 | 넣기(LMB)만. 빼기 없음 | 넣기 프리뷰, RMB 빼기(맨 위부터)와 꺼내기 강조 추가(Q59 B) |

## 기능 명세 판단 사항 (QNA에서 묻지 않고 정함, 2026-09-30 사용자 인정)

| ID | 판단 | 이유 |
|---|---|---|
| J1 | 모든 수금(음료 공용 수거함, 안마의자 동전함, 세신 현금)은 조준 E이며 들고 있는 물건과 무관하다. Q48 A 문구의 "빈손 E"를 Q42 수정과 같게 맞춘다 | 기존 계산대 현금 받기도 들고 있는 물건과 무관하다. 수금 대상에는 E "두기"가 없어 충돌하지 않는다 |
| J2 | 동전함에 돈이 남은 안마의자를 회수하면 남은 돈은 회수가 확정되는 순간 지갑에 들어간다. 설비 아이템에 돈을 보존하지 않는다 | 수거 구역에 실수로 둬서 돈을 잃는 일을 막는다 |
| J3 | 꺼내기 표시(Q53)는 꺼내기가 있는 모든 대상에 적용한다: 냉장고, 화장대, 샤워 비품, 수건 선반, 사용 수건통, 세탁기·건조기. 다음에 빠지는 것은 항상 마지막에 넣은 것(맨 위층)이다. 세탁기·건조기는 기계에 가려 잘 보이지 않아도 기계 안의 실제 수건을 강조한다(2026-09-30 사용자 지정). | 수건 표현은 무작위 위치에 쌓이지만 빠지는 순서는 마지막에 넣은 것부터로 정해져 있다 |

| J6 | 샤워 비품은 손님이 샤워기에서 씻기를 한 번 시작할 때마다 줄어든다. 현재 손님 루틴의 목욕 전 샤워와 목욕 후 샤워는 각각 한 번이다 | Q48 A "샤워기를 한 번 쓸 때"를 현재 루틴에 맞춰 해석 |
| J7 | 샤워기 한 대(손님 자리 2개)의 비품은 두 자리가 함께 쓴다 | Q20 A "샤워기마다 종류별 2병" |
| J8 | 손님이 이용 중인 동안에도 플레이어는 진열 서비스에 넣기·꺼내기를 할 수 있다. 회수만 막힌다 | 보충을 막으면 손님이 많을 때 보충할 수 없다 |

| J10 | 묶은 쓰레기봉투를 정면에 놓을 공간이 없으면 꺼내지 않고 이유를 보이며 봉투 내용은 그대로다 | 벽에 붙어 RMB를 눌렀을 때 봉투가 벽 속에 생기지 않게 |

| J18 | 상점 가격은 아래 "상점 상품" 표의 임시 기본값을 쓰고 모두 상점 목록에서 조정한다 | QNA에서 가격을 정하지 않았다 |
| J19 | 새 도구(집게+봉투, 때수건)는 기존 도구처럼 레벨에 하나씩 놓이고 전용 거치대가 있다. 상점에서 팔지 않는다 | Q24·Q28 B "레벨 도구, 거치대" |
| J20 | 품목 박스 겉모양은 종류와 관계없이 하나이고, 내용물 종류는 HUD로 확인한다 | 박스 종류가 내용물로 바뀌므로(Q16 수정) 겉모양을 종류별로 두면 빈 박스에 다른 물품을 담았을 때 겉과 속이 달라진다 |
| J21 | 품목 박스를 떨어뜨리거나 던져도 내용물이 쏟아지지 않는다 | 수건바구니와 같다. 쏟아진 물품을 줍는 규칙을 새로 만들지 않는다 |

## 공통 — 품목 박스

품목 박스는 같은 종류 물품 여러 개가 든 휴대물이다.

- 빈손 E로 들고, G로 내려놓는다. 한 번에 하나만 든다(기존 한 개 소지 규칙). 지정 거치대는 없다.
- 박스 하나에는 한 번에 한 종류만 들어간다. **박스의 종류는 들어 있는 물품이 정한다**(Q16, 2026-09-30 사용자 수정). 빈 박스는 종류가 없고, 처음 담은 물품이 박스 종류가 되며, 다시 비면 종류가 풀린다(수건바구니와 같은 규칙).
- 박스 정원은 들어 있는 종류의 박스 기본 수량이다(아래 표). 빈 박스는 무엇이든 그 종류의 정원까지 담을 수 있다.
- 다 비워도 빈 박스로 남는다(Q4 A). 빈 박스로 어떤 종류든 꺼내 담을 수 있다.
- 박스 겉모양은 종류와 관계없이 하나다(J20). **위가 열린 박스**라서 안에 든 물품이 보이고, 넣고 빼면 보이는 물품 수가 늘고 준다(2026-09-30 사용자 지정).
- 박스 안 물품은 종류마다 정해진 자리에 가지런히 놓인다. 채울 때는 정해진 순서대로, 뺄 때는 마지막에 넣은 것부터 빠진다.
- 박스 크기는 가장 큰 배치가 들어가는 크기로 정하고, 다른 종류는 그 안에 맞춰 배치한다.
- 박스를 떨어뜨리거나 던져도 내용물은 쏟아지지 않는다(J21).
- 상점에서 산 박스는 그 품목이 정원만큼 든 상태로 나온다.
- 품목 박스에는 수건을 담을 수 없고, 수건바구니에는 품목을 담을 수 없다.
- 박스를 조준하거나 들고 있으면 HUD에 "종류 현재/정원"(예: "바나나우유 7/12"), 빈 박스는 "빈 박스"가 보인다.
- 소모품 박스에는 새것만 들어간다. 박스 안에서는 사용 횟수가 줄지 않는다.
- 버릴 수 있는 종류다(빈 박스 포함). 수거 구역에 두면 수거된다.

| 담긴 종류 | 박스 정원 | 성격 |
|---|---:|---|
| 바나나우유 | 12병 | 판매 음료 |
| 헤어드라이기 | 2개 | 비품 |
| 스킨로션 | 6병 | 소모품, 1병 10회 |
| 면봉 | 6통 | 소모품, 1통 30회 |
| 빗 | 12개 | 비품 |
| 샴푸 | 6병 | 소모품, 1병 30회 |
| 바디워시 | 6병 | 소모품, 1병 30회 |

## 공통 — 진열

### 조준 대상

| 시설 | 조준 대상 | 넣을 자리 결정 |
|---|---|---|
| 음료 냉장고 | 진열 공간(선반 단) 하나하나가 따로 조준 대상 | 조준한 공간 |
| 공용 화장대 | 화장대 전체 | 들고 있는 박스 종류에 맞는 품목 자리로 자동(Q51 B). 빈 박스로 뺄 때는 조준한 지점에서 가장 가까운 품목 자리(Q61 A) |
| 샤워기 비품 | 샤워기 전체 | 들고 있는 박스 종류에 맞는 비품 자리로 자동(Q51 B). 빈 박스로 뺄 때는 조준한 지점에서 가장 가까운 비품 자리(Q61 A) |

### 넣기·꺼내기

- 품목 박스를 들고 대상을 조준해 **LMB를 누르면 1개 넣는다.** 누르고 있으면 기본 0.15초 간격으로 1개씩 이어서 넣는다.
- **RMB를 누르면 1개 꺼내** 박스에 담는다. 빈 박스나 같은 종류가 든 박스일 때만 가능하고, 박스 정원까지 담는다. 누르고 있으면 연속으로 꺼낸다.
- 진열 자리 안의 물품은 항상 첫 자리부터 채워 보인다. 넣으면 다음 빈자리에 놓이고, 꺼내면 마지막으로 채운 자리부터 빠진다(J4). 자리 위치와 순서는 Editor에서 정한다.
- 연속 옮기기는 다음 중 하나면 멈춘다: 박스 가득 참 또는 빔, 자리 가득 참 또는 빔, 종류가 맞지 않게 됨, 꺼낼 수 있는 것이 사용 중인 것만 남음, 조준이 대상에서 벗어남, 키를 뗌, 박스를 내려놓음, 컴퓨터·배치 모드 진입. 멈춘 뒤 누른 채 다시 조준해도 자동으로 다시 시작하지 않는다(조작 통일 규칙과 같음).
- 각 1개 이동은 완전히 성공하거나 아무 변화가 없다. 이미 옮긴 것은 되돌리지 않는다.
- 박스를 든 채 진열 대상에 E·F를 눌러도 옮기지 않는다.
- 박스를 든 채 진열 대상이 아닌 곳에 LMB·RMB를 누르면 아무 일도 없다.

거부와 HUD 이유:

| 상황 | LMB 넣기 | RMB 꺼내기 |
|---|---|---|
| 박스가 빔 | 거부 "박스가 비어 있음" | 가능. 꺼낸 물품의 종류가 박스 종류가 됨 |
| 박스가 가득 참 | 가능 | 거부 "박스 가득 참" |
| 자리 가득 참 | 거부 "가득 참" | 가능 |
| 자리에 그 종류가 없음 | 가능 | 거부 "꺼낼 물건 없음" |
| 냉장고 공간이 다른 음료로 정해짐 | 거부 "다른 음료가 진열됨" | 거부 "다른 음료가 진열됨" |
| 그 시설에 없는 품목이 든 박스(예: 샴푸가 든 박스로 화장대) | 거부 "여기에 넣을 수 없는 물건" | 거부 "여기에 넣을 수 없는 물건" |
| 남은 소모품이 사용 중인 것 1개뿐 | 해당 없음 | 거부 "사용 중인 것은 꺼낼 수 없음" |

- HUD는 조작 통일 규칙대로 가능한 동작을 LMB·RMB 키별로 함께 보여 주고, 할 수 없는 쪽에는 위 짧은 이유를 보인다.

### 넣기 프리뷰 (Q52 A)

- 넣을 수 있는 박스를 들고 대상을 조준하는 동안, 다음에 채워질 자리에 넣을 물체의 **반투명 모습**이 보인다.
- 넣으면 즉시 그다음 빈자리로 옮겨 간다. 가득 차면 사라진다.
- 넣을 수 없으면 프리뷰를 띄우지 않고 HUD에 이유만 보인다.
- 프리뷰는 플레이어 화면의 표시일 뿐이다. 충돌이 없고 손님·물리·배치 판정에 영향을 주지 않는다.
- 설비 배치 모드의 설비 미리보기와는 별개다.

### 꺼내기 표시 (Q53, Q56 A, J3)

- 꺼낼 수 있는 박스를 들고 대상을 조준하는 동안, 다음에 빠질 물체(마지막 채운 자리)를 **외곽선 강조**로 표시한다.
- 넣기 프리뷰와 동시에 보일 수 있다(같은 종류가 조금 든 박스).
- 켜고 끌 수 있는 옵션이며 기본 켜짐이다. 지금은 Editor 프로젝트 설정에서 바꾸고, 게임 설정 메뉴가 생기면 그곳으로 옮긴다. 넣기 프리뷰는 옵션이 아니다.

### 진열 수량 표시 (Q6 A)

- 시설에 진열된 수량만큼 물품이 외형으로 보인다.
- 시설을 조준하면 HUD에 종류별 "현재/최대"가 보인다. 소모품은 "새것 n + 사용 중 남은 횟수/전체 횟수"를 함께 보인다(예: "스킨로션 새것 2 + 사용 중 7/10회").
- 박스를 들지 않아도 조준 HUD는 보인다.

### 회수와 버리기 (Q5 A, Q55 A)

- 진열 서비스 설비는 기존 설비처럼 Q Hold로 회수한다.
- **손님이 이용 중(이용하려고 자리를 잡은 경우 포함)이면 회수할 수 없다.** Q Hold를 시작하지 않고 이유를 보인다.
- 회수하면 진열 자리별 종류·수량과 쓰는 중인 소모품의 남은 횟수가 설비 아이템에 그대로 보존되고, 다시 배치하면 그대로 복원된다. 냉장고 진열 공간의 음료 종류도 복원된다.
- 설비 아이템을 조준하거나 들면 HUD에 내용물 요약이 보인다.
- 안마의자 동전함에 남은 돈은 회수가 확정되는 순간 지갑에 들어간다(J2). 냉장고에는 돈이 쌓이지 않으므로 회수와 무관하다. Q Hold를 취소하면 돈과 내용물 모두 그대로다.
- 내용물이 든 설비 아이템을 수거 구역에 두면 내용물도 함께 수거되어 사라진다. 환불은 없다.

## 음료 냉장고

- 상점에서 사서 배송 상자로 받고, 설비 아이템으로 배치·회수한다.
- 진열 공간 4개(선반 4단), 공간당 6병, 전체 24병(Q49 A). 공간 수와 공간당 정원은 Editor에서 조정한다.
- 진열 공간 하나가 하나의 조준 대상이다. 한 공간에는 한 종류만 들어간다.
- 빈 공간은 종류가 없고, 처음 넣은 음료가 그 공간의 종류가 된다. 다시 비면 종류가 풀린다(Q50 A).
- 음료는 바나나우유 1종으로 시작한다. 종류를 나중에 추가할 수 있어야 한다(Q7 A).
- 진열 공간 조준 HUD: "바나나우유 4/6" 또는 "빈 공간 0/6".
- 냉장고에는 돈을 모으는 곳이 없다. 음료 값은 모든 냉장고가 함께 쓰는 **음료 공용 수거함**에 쌓인다(2026-09-30 사용자 지정).

### 음료 공용 수거함

- 카운터에 비치된 레벨 고정물 하나다. 상점에서 팔지 않고 배치·회수·들기·수거 대상이 아니다. 위치는 레벨에서 정한다.
- 어느 냉장고에서 팔린 음료든 값이 이곳에 쌓인다.
- 조준하면 HUD에 모인 금액이 보이고, E를 누르면 모인 돈이 모두 지갑에 들어가 0이 된다. 들고 있는 물건과 무관하다(J1). 0원이면 E는 아무 일도 하지 않고 "모인 돈 없음"을 보인다.
- 기존 계산대의 손님 입장료 현금 받기와는 별개이며 그 흐름을 바꾸지 않는다.

손님 이용(Q48 A, J9):

- 냉장고 한 대는 한 번에 손님 1명이 이용한다.
- 손님은 음료가 든 진열 공간 중 하나에서 1병을 가져간다. 그 공간의 마지막 채운 자리에서 빠진다.
- 병이 냉장고에서 사라지는 순간 음료 공용 수거함에 음료 값(기본 2,000원)이 쌓인다(J9).
- 모든 공간이 비었으면 손님이 이용할 수 없다.
- 가져간 병은 손님과 함께 사라진다. 빈 병 쓰레기는 쓰레기 생성 규칙으로만 생긴다.

## 공용 화장대

- 상점에서 사서 배치·회수한다. 1인용이며 의자 없이 서서 쓴다(Q12 A).
- 품목 4종과 정원(Q10 B, Q11 A):

| 품목 | 성격 | 화장대 정원 | 사용 횟수 |
|---|---|---:|---|
| 헤어드라이기 | 비품(줄지 않음) | 2 | — |
| 스킨로션 | 소모품 | 4병 | 1병 10회 |
| 면봉 | 소모품 | 4통 | 1통 30회 |
| 빗 | 비품(줄지 않음) | 6 | — |

- 품목마다 정해진 자리가 있고 다른 품목 자리에는 들어가지 않는다. 화장대 전체를 조준하면 들고 있는 박스 종류의 자리로 넣고 꺼낸다(Q51 B). 넣기 프리뷰와 꺼내기 표시도 그 품목 자리에 뜬다.
- 소모품은 품목마다 **쓰는 중인 것 1개만** 횟수가 준다. 다 쓰면 그것이 사라지고, 다음 이용 때 다음 새것이 쓰는 중인 것이 된다(Q17 A).
- 쓰는 중인 것은 꺼낼 수 없다. 꺼내기는 새것만, 마지막 채운 자리부터다.
- 빈 박스를 들고 화장대를 조준하면 조준한 지점에서 가장 가까운 품목 자리가 뺄 대상이 되고, 그 자리의 다음에 빠질 물품이 강조된다. 그 자리가 비었거나 남은 것이 쓰는 중인 소모품뿐이면 거부하고 이유를 보인다. 다른 자리에서 대신 빼지 않는다(Q61 A). 첫 1개를 빼는 순간 박스 종류가 정해지므로, 그 뒤로는 조준 지점과 관계없이 그 품목 자리에서만 빠진다(물품이 든 박스 규칙). 연속 빼기는 화장대를 벗어나지 않는 한 그 자리 묶음에서 계속된다(2026-09-30 정정).
- 조준 HUD: 네 품목의 현재/최대와 소모품의 사용 중 남은 횟수.

손님 이용(Q48 A, J5, J8):

- 화장대 한 대는 한 번에 손님 1명이 기본 20초 이용한다.
- 이용을 시작하는 순간 스킨로션·면봉의 쓰는 중인 것(없으면 새것 1개가 쓰는 중이 됨)에서 각각 1회 준다. 드라이기·빗은 줄지 않는다.
- 품목이 없으면 그 품목 없이 이용한다. 화장대가 완전히 비어 있어도 이용할 수 있다. 무료다.
- 이용 중에도 플레이어는 넣기·꺼내기를 할 수 있다. 회수는 막힌다.
- 이용할 수 없는 조건: 다른 손님이 이용 중, 회수 Q Hold 진행 중.

## 샤워 비품

- 기존 샤워기(레벨에 미리 놓인 것과 상점에서 산 것 모두)에 비품 자리가 생긴다(Q20 A).
- 샴푸·바디워시 2종, 샤워기 한 대에 종류별 2병(Q19 A, Q20 A). 1병 30회(Q21 A).
- **모든 샤워기는 비품이 빈 상태로 시작한다**(Q21 A).
- 샤워기 전체를 조준하면 박스 종류의 자리로 넣고 꺼낸다(Q51 B). 넣기 프리뷰와 꺼내기 표시는 그 비품 자리에 뜬다.
- 쓰는 중인 것 1개만 횟수가 줄고, 쓰는 중인 것은 꺼낼 수 없다(화장대 소모품과 같은 규칙).
- 샤워기 한 대의 손님 자리 2개는 비품을 함께 쓴다(J7).
- 빈 박스를 들고 샤워기를 조준하면 조준한 지점에서 가장 가까운 비품 자리에서 뺀다(화장대와 같음, Q61 A).
- 조준 HUD: 샴푸·바디워시의 현재/최대와 사용 중 남은 횟수.

손님 이용(Q48 A, J5, J6):

- 샤워기의 점유·이용 시간은 기존 손님 샤워 규칙 그대로다.
- 손님이 그 샤워기에서 씻기를 한 번 시작할 때마다 샴푸·바디워시의 쓰는 중인 것에서 각각 1회 준다. 목욕 전 샤워와 목욕 후 샤워는 각각 한 번이다.
- 비품이 없으면 비품 없이 샤워한다. 무료다.
- 샤워기는 손님이 이용 중(자리를 잡은 경우 포함)이면 회수할 수 없다. 회수하면 비품이 보존되고 재설치 시 복원된다(Q55 A).

## 기존 수건 시스템 — 프리뷰와 표시 (Q54, J3)

이동 방향과 조건은 조작 통일 규칙 그대로이고 표시만 더한다.

| 대상 | 넣기 프리뷰(LMB) | 꺼내기 표시(RMB, 옵션) |
|---|---|---|
| 수건 선반 | 깨끗한 수건이 든 바구니로 넣을 수 있을 때, 다음 수건이 쌓일 자리(맨 위)에 반투명 수건 | 빈 바구니나 깨끗한 수건 바구니로 뺄 수 있을 때, 맨 위 수건 강조 |
| 대기 세탁기 | 사용한 수건 바구니로 넣을 수 있을 때, 기계 안에서 다음 수건이 놓일 **정확한 자리**에 반투명 수건 | 빈 바구니나 사용한 수건 바구니로 뺄 수 있을 때, 다음에 빠질 수건(마지막에 넣은 것) 강조 |
| 대기 건조기 | 젖은 수건 바구니로 넣을 수 있을 때, 기계 안 다음 자리에 반투명 수건 | 빈 바구니나 젖은 수건 바구니로 뺄 수 있을 때, 다음에 빠질 수건 강조 |
| 사용 수건통 | 해당 없음(플레이어가 넣지 않음) | 사용한 수건을 담을 수 있는 바구니를 들고 조준하면 맨 위 수건 외곽선 강조 |
| 완료 세탁기·건조기 | 해당 없음 | 빈 바구니나 같은 상태 바구니를 들고 조준하면 기계 안에서 다음에 빠질 수건(마지막에 넣은 맨 위층 수건) 외곽선 강조. 기계에 가려 잘 보이지 않아도 실제 수건에 표시 |
| 작동 중 기계 | 표시 없음 | 표시 없음 |

- 넣을 수 없으면(가득 참, 상태 불일치, 작동 중, 바구니 빔) 프리뷰 없이 기존 HUD 이유만 보인다.
수건 선반 빼기(Q59 B, 기존 수건 이동 조건 변경):

- 빈 바구니나 깨끗한 수건이 든 바구니를 들고 수건 선반을 조준해 RMB를 누르면 맨 위 수건 1장이 바구니로 옮겨진다. 누르고 있으면 연속이며, 바구니 정원까지 담는다.
- 다른 상태 수건이 든 바구니는 거부하고 "다른 상태의 수건"을 보인다. 선반이 비면 "꺼낼 수건 없음"을 보인다.
- 손님이 선반에서 수건을 가져가는 것과 동시에 일어나도 각 1장 이동은 완전히 성공하거나 변화가 없다.

세탁기·건조기 세부(Q54, 2026-09-30 사용자 지정 — 진열대와 같은 규칙):

- **다음 자리는 넣기 전에 정해져 있다.** 기계 안의 수건 자리는 무작위로 흩어져 보이지만, 다음 수건이 놓일 자리는 넣기 전에 이미 정해져 있다. 넣기 프리뷰는 그 자리에 뜨고, LMB로 넣으면 수건이 **프리뷰가 보이던 바로 그 자리**에 놓인다. 조준을 뗐다가 다시 해도 다음 자리는 바뀌지 않는다.
- 넣으면 프리뷰는 그다음 자리로 옮겨 간다. 기계 안에서는 아래층부터 쌓인다.
- **대기 상태에서도 빼기 허용(2026-09-30 사용자 지정, 기존 수건 이동 조건 변경):** 대기 기계를 조준하고 RMB를 누르면 1장씩 바구니로 옮긴다. 누르고 있으면 연속이다. 빈 바구니나 기계 안과 같은 상태의 수건이 든 바구니만 되고, 바구니 정원까지 담는다. 다른 상태 바구니는 거부하고 "다른 상태의 수건"을 보인다.
- 상태별로 가능한 것: 대기는 넣기·빼기 모두, 완료는 빼기만, 작동 중은 둘 다 불가.
- 빼면 마지막에 넣은 수건(맨 위층)부터 빠진다. 대기 상태에서 뺀 뒤 다시 넣으면 방금 빠진 그 자리에 놓인다(진열대와 같음).
- 기계가 완전히 비면 다음 자리 배치를 새로 무작위로 정한다. 그래서 매번 같은 모양으로 쌓이지 않는다. 대기 상태에서 모두 빼도 기계는 대기 상태 그대로다.
- 세탁·건조로 수건 상태가 바뀌어도 자리는 그대로다(기존 규칙).
- **뚜껑·문 자동 열림:** 넣거나 뺄 수 있는 바구니를 들고 기계를 조준하는 동안 뚜껑(수직형)이나 문(수평형)이 저절로 열려 안이 보인다. 조준이 벗어나거나, 넣고 뺄 수 없는 상태가 되거나, 작동을 시작하면 닫힌다. 작동 중에는 열리지 않는다. 보일러 투입구 문 자동 열림과 같은 원칙이며 수건 이동 조건은 바꾸지 않는다.
- 기계 모델(초반 수직형 통돌이, 중급 이상 수평형 드럼)이 달라도 규칙은 같다. 기계마다 Editor에서 통 안 범위와 뚜껑·문 열림 모양을 정한다.

## 쓰레기

### 생성 (Q22, Q33 A, Q23 A)

- Editor에서 정한 **쓰레기 생성 구역** 안에서 생긴다. 쓰레기 생성 구역과 물 얼룩 생성 구역은 각각 Editor에서 정한다(같은 영역을 써도 된다).
- 구역마다 따로 계산한다. 그 구역 범위 안에 있는 **손님** 1명당 평균 120초에 1개꼴로 무작위 시점에 생긴다. 손님 n명이면 평균 120/n초 간격이다. 플레이어는 세지 않는다.
- 구역 안에 손님이 없으면 그 구역에는 생기지 않는다.
- 전체 최대 개수(기본 20)와 구역별 최대 개수에 도달하면 더 생기지 않는다. 치워서 줄면 다시 생긴다. 생길 자리를 찾지 못한 시점은 건너뛰고 나중에 몰아서 생성하지 않는다.
- **바닥에만** 생긴다. 욕탕 위(물 속 포함), 배치된 설비와 바닥에 놓인 물건 위나 그와 겹치는 자리, 벽 바로 옆(벽에 묻혀 보이는 자리)에는 생기지 않는다. 플레이어·손님의 위치와는 관계없이 생기며 발밑에도 생길 수 있다(2026-10-01 사용자 지정). 기존 쓰레기와 최소 간격을 둔다. 물 얼룩과는 겹쳐 생길 수 있고, 쓰레기가 얼룩 위에 있으면 쓰레기를 먼저 치워야 그 얼룩을 닦을 수 있다(Q62 B). 쓰레기의 대상 이름은 "쓰레기" 하나다. LMB에 자기 행동이 없는 물건(빈손·품목 박스·수건바구니·삽 등)으로 조준하면 LMB 이유 "집게가 필요합니다"가 보이고, 대걸레·몽키스패너·배송 상자·설비 아이템은 기존 LMB 행동을 그대로 표시·실행한다(Q63 A, 2026-09-30 정정).
- 외형은 빈 병, 쓴 면봉, 휴지 뭉치 등 여러 종이며 규칙은 같다.
- 생긴 자리에 고정되어 밀리지 않는다(J11). 플레이어·손님의 이동은 막지 않는다. 수거 구역이 수거하지 않으며 집게로만 치운다.
- 게임에 영향이 없다. 쌓이는 것이 보이기만 한다(Q25 A).
- 설비 배치를 확정하는 순간 그 설비의 설치 자리와 조금이라도 겹치는 쓰레기·물 얼룩은 모두 사라진다(Q57 A, Q64 A). 배치 미리보기 단계에서는 사라지지 않고, 배치를 취소하면 그대로 남는다. 쓰레기·물 얼룩은 배치를 막지 않는다.

### 집게+봉투 도구 (Q24, Q34 A, Q35 A, J19)

- 레벨에 하나 놓인 도구이며 전용 거치대가 있다. 빈손 E로 들고, 거치대 조준 E로 보관, G로 내려놓는다. 거치대 보관·내려놓기 동안 봉투 내용은 유지된다.
- 도구에는 봉투가 끼워져 있고 봉투 정원은 기본 20개다. 들고 있으면 HUD에 "봉투 n/20"이 보인다.
- **LMB 줍기:** 쓰레기를 조준하고 LMB를 누르면 한 개를 주워 봉투에 담고 그 쓰레기가 사라진다. 누르고 있어도 한 개만 줍는다. 다음 쓰레기는 조준 후 다시 누른다.
- 봉투가 가득 차면 줍지 않고 "봉투 가득 참"을 보인다.
- **RMB 묶어 꺼내기:** 봉투에 1개 이상 있으면 언제든 RMB로 묶은 쓰레기봉투를 플레이어 정면 바닥에 내놓는다. 도구에는 즉시 새 빈 봉투가 끼워진다. 봉투 수 제한은 없다.
- 빈 봉투는 꺼낼 수 없고 "봉투가 비어 있음"을 보인다.
- 정면에 봉투를 놓을 공간이 없으면 꺼내지 않고 "봉투를 놓을 공간이 없음"을 보이며 봉투 내용은 그대로다(J10, Q65 A).
- 집게를 든 채 쓰레기가 아닌 곳에 LMB를 누르면 아무 일도 없다. 쓰레기는 빈손 E나 다른 도구로 줍지 않는다.

### 묶은 쓰레기봉투

- 한 개 소지 규칙을 따르는 휴대물이다. 빈손 E로 들고 G로 내려놓는다. 물리적으로 떨어지고 굴러간다.
- 조준하거나 들면 HUD에 "쓰레기봉투 (n개)"가 보인다. 다시 풀 수 없다.
- 버릴 수 있는 종류다. 수거 구역에 두면 수거된다.

## 물 얼룩 생성 변경 (Q22, Q33 A)

- 쓰레기와 같은 규칙으로 바꾼다: 구역마다 따로, 구역 안 손님 1명당 평균 간격마다 무작위, 손님 없는 구역은 생성 없음, 전체·구역별 최대 유지, 바닥에만. 기존의 플레이어·손님과 겹침 방지는 없애고, 벽 바로 옆에는 생기지 않는다(2026-10-01 사용자 지정).
- 1명 기준 평균 간격은 현재 설정된 생성 간격 값을 그대로 쓴다.
- 욕탕 위, 배치된 설비·바닥에 놓인 물건 위에는 생기지 않는다.
- 설비 배치를 확정하면 설치 자리 안의 물 얼룩이 사라진다(Q57 A, 쓰레기와 같음).
- 얼룩 외형 변화, 물걸레 청소 규칙은 그대로다.

## 쓰레기 수거 구역 (Q36~Q39)

- Editor에서 위치·크기를 정하는 바닥 구역이다. 플레이어가 경계를 알아볼 수 있게 바닥에 표시된다. 가게 밖 등 위치는 Editor에서 정한다.
- G로 내려놓거나 굴러 들어가 구역 안에 놓인 휴대물이 수거 대상이다. 물건의 중심이 구역 안에 있으면 구역 안으로 본다. 구역 안에 배치 확정된 설비는 휴대물이 아니므로 수거하지 않는다.
- **수거:** 날짜 시스템이 생기기 전에는 기본 300초(조정 가능)마다 수거한다. 수거 시점에 구역 안에 있고 플레이어가 들고 있지 않은 **버릴 수 있는 종류**가 모두 사라진다. 날짜 시스템이 생기면 수거 시점을 "다음 날 시작"으로 바꾼다.
- 버릴 수 있는 종류(Q37 A): 판매 목록 종류의 설비 아이템(내용물 포함), 배송 상자(내용물 포함), 품목 박스(빈 박스 포함), 묶은 쓰레기봉투.
- 남는 것: 열쇠, 레벨 도구(대걸레·몽키스패너·수건바구니·삽·집게+봉투·때수건), 락커 아이템, 바닥의 사용한 수건, 그 밖에 버릴 수 없는 모든 것.
- 수거로 돈은 바뀌지 않는다. 다음 수거 시점은 표시하지 않는다(Q58 A).

### 기존 쓰레기통 (Q39 A)

- 쓰레기통을 레벨에서 뺀다. 쓰레기통 기능은 코드에 남기되 게임에서 쓰지 않는다.
- 상점 계약의 "들고 쓰레기통 조준 E = 버리기"는 "수거 구역에 두면 다음 수거 때 사라짐"으로 바뀐다. 버릴 수 있는 종류의 판정은 쓰레기통 규칙과 같다.
- 조작 통일 작업(CTRL-028)의 쓰레기통 E는 그 작업에서 그대로 두고, 이 변경은 쓰레기·수거 구현 단위(3번)에서 처리한다.

## 안마의자 (Q26, Q41~Q43)

- 상점에서 사서 배치·회수한다. 손님이 이용 중이면 회수할 수 없다.
- **손님 이용:** 한 대에 1명, 기본 60초. 비어 있고 고장 나지 않은 안마의자만 이용한다. 이용이 끝나면 요금(기본 3,000원)이 **동전함**에 쌓인다.
- **수금:** 안마의자를 조준하면 HUD에 모인 금액과 상태(정상·고장·이용 중)가 보인다. E를 누르면 모인 돈이 지갑에 들어간다. 들고 있는 물건과 무관하다. 손님이 이용 중이어도 수금할 수 있다. 0원이면 "모인 돈 없음".
- **고장:** 이용이 끝나 요금이 쌓인 뒤 기본 10% 확률로 고장 난다(J12). 고장 나면 외형으로 알 수 있고 손님이 이용하지 않는다. 동전함 수금은 고장 중에도 된다.
- **수리:** 몽키스패너를 들고 고장 난 안마의자를 조준해 LMB를 누르고 있으면 진행 표시가 차고, 기본 3초 뒤 정상이 된다. 조준이 벗어나거나 LMB를 떼면 진행이 처음으로 돌아간다. 수리 중에는 휘두르기 타격이 일어나지 않는다(J13). 정상 안마의자를 조준한 LMB는 기존 휘두르기다.
- 고장 상태는 회수·재설치해도 유지된다. 동전함의 돈은 회수 확정 시 지갑에 들어간다(J2).

## 세신 (Q27, Q28 B, Q44~Q47)

### 세신대와 때수건

- 세신대는 상점에서 사서 배치·회수한다. 손님이 누워 있거나 세신 중이면 회수할 수 없다.
- 때수건은 레벨에 하나 놓인 도구이며 전용 거치대가 있다. 빈손 E로 들고, 거치대에 E로 보관, G로 내려놓는다. 소모되지 않는다(Q47 A).

### 손님 대기

- 세신대 한 대에 손님 1명이 눕는다. 손님이 누운 순간부터 **대기 한도**(기본 90초)가 흐른다.
- 세신대를 조준하면 HUD에 남은 대기 시간과 진행 게이지가 보인다.
- 대기 한도가 지나면 손님이 요금 없이 일어나 떠나고, 진행하던 게이지도 함께 사라진다(Q46 A). 대기 한도는 포커스 중에도 흐른다(J14).

### 세신 포커스 진입·이탈 (Q44 B, 2026-09-30 사용자 지정: 컴퓨터와 같은 포커스인·아웃)

세신 작업은 컴퓨터 사용과 같은 방식으로 들어가고 나온다.

- **진입:** 때수건을 들고 손님이 누운 세신대를 조준해 E를 누른다. 시점이 부드럽게 세신대의 고정 세신 시점으로 옮겨 간다. 진입 시간은 Editor에서 조정한다.
- 진입할 수 없으면 E를 눌러도 들어가지 않고 이유를 보인다: 때수건을 들지 않음("때수건이 필요합니다"), 누운 손님 없음("세신할 손님 없음"), 이미 게이지가 다 참.
- **포커스 중 조작:**
  - 시점이 고정되어 마우스를 움직여도 시점이 돌지 않는다. 마우스 움직임은 문지르기에만 쓰인다.
  - 때수건이 손님 몸 위에서 마우스를 따라 움직인다. 움직일 수 있는 범위는 세신대 위로 제한된다.
  - LMB를 누른 채 마우스를 움직이면 움직인 양만큼 게이지가 찬다. 가만히 누르고만 있거나 LMB를 떼고 움직이면 차지 않는다. 필요한 문지르기 양은 Editor에서 조정한다.
  - 화면에 진행 게이지와 남은 대기 시간이 보인다.
  - 이동, 점프, G 내려놓기, Q Hold 회수, 다른 상호작용은 포커스 중에 동작하지 않는다.
- **이탈:** 포커스 중 E 또는 ESC를 누르면 나온다. 진입에 쓴 E를 누르고 있는 것만으로는 나오지 않는다. 나오는 도중 추가 E·ESC는 무시한다.
- **자동 이탈:** 게이지가 다 차거나, 대기 한도가 지나 손님이 떠나면 저절로 나온다.
- 이탈하면 캐릭터는 세신대마다 Editor에서 정한 이탈 위치에 정한 방향을 보고 선다. 그 자리가 막혀 있으면 근처 빈자리에 선다(컴퓨터 포커스아웃과 같은 규칙). 시점은 캐릭터 시점으로 부드럽게 돌아온다.
- 나와도 때수건은 계속 들고 있다. 중간에 나오면 찬 게이지는 유지되고, 다시 진입해 이어서 문지를 수 있다(J14).
- 세신 포커스 중에는 컴퓨터·배치 모드에 들어갈 수 없다.

### 완료와 요금

- 게이지가 다 차면 포커스에서 나오고, 손님이 일어나 세신대 옆에서 현금(기본 20,000원)을 내민다. 플레이어가 조준 E로 받으면 지갑에 들어가고 손님이 떠난다. 들고 있는 물건과 무관하다(J1, J15).
- 손님이 일어나는 순간 세신대는 다음 손님이 쓸 수 있다.

## 휴게 공간 (Q29 A, Q30 B)

- 평상과 TV는 각각 상점에서 사서 배치·회수하는 설비다.
- 평상: 좌석 수는 평상마다 Editor에서 정하며 기본 3이다(J16). 손님이 앉아 있으면 회수할 수 없다. 이용 시간·효과는 손님 루틴 작업에서 정한다. 소모·돈·고장 변화가 없다.
- TV: **빈손 E**로 켜고 끈다. 화면으로 켜짐·꺼짐이 보인다. 무언가 들고 있으면 켜고 끌 수 없고 "빈손으로 켜고 끌 수 있음"을 보인다. 새로 설치하거나 재설치하면 꺼진 상태다(J17). TV 켜짐에 따른 손님 효과는 손님 루틴 작업에서 정한다.

## 실패·취소·복구

- 진열 넣기·꺼내기, 쓰레기 줍기, 봉투 꺼내기, 수금은 각 1회가 완전히 성공하거나 아무 변화가 없다.
- 회수 Q Hold 취소: 내용물·동전함·고장 상태·TV 전원 모두 원래대로다.
- 박스·도구를 떨어뜨리거나 레벨 밖으로 떨어지는 경우의 복구는 기존 휴대물 규칙을 따른다. 레벨 도구(집게+봉투, 때수건)는 거치대로, 박스·쓰레기봉투는 기존 비도구 휴대물 규칙대로 돌아오며 내용은 보존된다.
- 연속 옮기기, 수리 진행 중 컴퓨터·배치 모드 진입, 물건 내려놓기, 거치대 보관이 일어나면 진행이 멈춘다. 수리 진행은 초기화된다.
- 세신 포커스 중 손님이나 세신대가 비정상적으로 사라지면 포커스에서 나오고 캐릭터 시점으로 돌아온다. 게이지는 손님과 함께 사라진다.

## 기존 기능 유지 범위

- 조작 통일 규칙 전체(LMB 들고 있는 물건 효과, RMB 반대 방향, E 손으로 하는 일, G, Q Hold, 컴퓨터 > 배치 > 장비 LMB 우선순위)
- 수건 이동 방향·조건·정원·상태 전환, 기계 대기·작동·완료. 예외: 대기 기계에서 빼기와 수건 선반 빼기를 새로 허용한다. 조작 통일의 CTRL-015(선반 RMB 거부)와 CTRL-016(대기 기계 RMB 거부) 결과를 진열 확장 구현 단위(2번)에서 바꾼다
- 샤워기의 기존 손님 샤워 흐름, 배치 규칙
- 물걸레 청소, 얼룩 외형 변화
- 상점 장바구니·주문·배송·개봉, 지갑과 계산대 현금 받기
- 몽키스패너 기존 휘두르기(고장 난 안마의자 조준 LMB 제외)
- 관련 없는 기존 결함을 포괄적으로 고치는 작업으로 넓히지 않는다.

- 쓰레기 외형 후보는 Editor에서 추가·교체할 수 있다.
- 새 음료 종류를 추가할 수 있어야 한다.

## 구현 단위 계획 (Q13 A, Q31 A)

각 단위는 수직 구현이다. C++와 Content, 입력·UI·시간 기반 동작, 휴대물 lifecycle이 함께 바뀌기 때문이다. 단위가 시작될 때 해당 절만 뽑아 메인 `.md/PROMPT_ARCHITECTURE.md`에 옮기고, 그때 필요한 사전 Unreal 조사를 정한다.

손님이 실제로 시설에 가는 행동은 손님 루틴 작업에서 만든다. 각 단위는 시설 쪽 손님 계약을 갖추며, 손님 행동 없이 어떻게 검증할지는 그 단위의 설계 단계가 정한다.

| 순서 | 단위 | 포함 | 대표 수직 시나리오 |
|---|---|---|---|
| 1 | 진열 기반(음료 냉장고) | 품목 박스 공통(내용물이 종류 결정, 열린 박스와 종류별 배치), 진열 공통(LMB 넣기·RMB 빼기·연속·넣기 프리뷰·꺼내기 강조와 옵션·HUD), 음료 냉장고, 카운터 음료 공용 수거함과 수금, 회수 보존, 상점 판매·개봉, 박스 버리기 판정(수거 구역 전까지는 기존 쓰레기통), 음료 손님 계약(시설 쪽) | 냉장고와 바나나우유 박스를 사서 배치 → 프리뷰를 보며 한 공간을 채우고 멈춤 → RMB로 빼기 → 공용 수거함 수금 → 회수·재설치 후 진열 유지 |
| 2 | 진열 확장 | 공용 화장대, 샤워 비품, 수건 시스템 변경(수건 선반·사용 수건통·세탁기·건조기 넣기 프리뷰·꺼내기 강조, 세탁기·건조기 다음 자리 미리 정하기와 뚜껑·문 자동 열림, 대기 기계 빼기, 수건 선반 빼기), 화장대 손님 계약(시설 쪽) | 1번 규칙을 쓰는 대상을 늘린다. 샴푸 박스로 샤워기를 채우고 실제 손님 샤워 한 번에 샴푸·바디워시가 각 1회 준다 |
| 3 | 쓰레기·수거 | 쓰레기 생성, 집게+봉투 도구, 묶은 봉투, 수거 구역, 쓰레기통 레벨 제거, 물 얼룩 생성 변경, 설비 배치 시 발밑 쓰레기·얼룩 제거 | 손님이 있는 구역에 쓰레기가 생김 → 집게로 주움 → RMB로 묶은 봉투 → 수거 구역에 두면 다음 수거 때 사라짐 |
| 4 | 배치형 서비스 | 안마의자(동전함·고장·수리), 평상, TV, 세신(포커스·미니게임·현금), 각 손님 계약(시설 쪽) | 안마의자 동전함 수금 → 고장 → 몽키스패너 3초 수리. 세신 포커스 진입 → 문지르기 → 현금 받기 |

- 1번은 박스·진열·프리뷰·강조 규칙을 처음 만드는 단위라 따로 둔다. 2번은 새 규칙 없이 1번 규칙을 적용하는 대상만 늘린다(Q60 B: 수건 변경은 1번에 넣지 않음).
- 2번은 조작 통일의 CTRL-015·016(수건 선반·대기 기계 RMB 거부) 결과를, 3번은 CTRL-028(쓰레기통 E) 결과를 바꾼다.
- 손님 루틴 없이 PIE에서 실제로 볼 수 있는 손님 계약은 샤워 비품 감소(2번)뿐이다. 세신은 손님이 누워야 미니게임이 가능하므로, 4번 시작 시 세신을 손님 루틴 작업 뒤로 미룰지 다시 판단한다.

사전 조사 후보(해당 단위에서 판단): 레벨의 쓰레기통·도구 거치대 위치, 물 얼룩 생성 구역과 현재 생성 간격 값, `BP_Shower` 손님 자리 구성, 세탁기·건조기 모델의 통 안 범위와 뚜껑·문, 입력 매핑의 RMB 연결 상태(조작 통일 결과).
