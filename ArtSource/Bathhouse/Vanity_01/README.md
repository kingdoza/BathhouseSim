# Vanity_01 — 레트로 화장대 (`BP_Vanity`용)

홀 구역 테마(`hall`, 나무): 황동 슈를 단 원목 테이퍼 다리, 테라코타 톤 나무 캐비닛(진한 나무 문 2 + 서랍 2, 아이보리 판넬, 크롬 손잡이, 열쇠 구멍), 크롬 테를 두른 아이보리 상판(Z=100), 아치형 거울(아이보리 테·황동 장식), 양옆 벽등 2개, −Y 측면 수건걸이로 구성했습니다. 정면은 UE +X입니다.

| FBX | BP component | 원점 | 크기·비고 |
|---|---|---|---|
| `SM_Vanity_01.fbx` | VanityBody | (0,0,0) 바닥 중심 | 63×134×180 (footprint 80×140×180), UCX 4개 |
